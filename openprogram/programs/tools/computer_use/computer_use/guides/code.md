Code: for loops, conditions or data handling, send code instead of action: Python with top-level await, run in an isolated interpreter (no files, network or processes) whose variables persist for the rest of this turn (macOS only). cu is the call's target: its methods are that target's actions with the same arguments, e.g. await cu.get_state(), await cu.click(element=3); dir(cu) lists them and help(cu.click) shows one. A call returns {"text": …, "json_data": …}; print what you want to see (up to 256 KB). What the call names (app, title, display) holds for every step: a step may leave it out and may not name another. Work on two targets takes two calls; variables carry over between them. Code reads text, not pictures: get_state returns the element tree in full, and on a target that shows pixels only, look with an action call. One call may take 120 seconds (timeout, 60 by default) and 100 actions. A step that fails raises; the steps before it stay made, so read the state before repeating. Example:
computer_use(type="window", app="Numbers", code="for value in ['3', '5', '8']:\n    await cu.type_text(text=value)\n    await cu.press_key(key='Return')")
