# Weekly reports

| Entry point | Purpose |
| --- | --- |
| `weekly_report` | Coordinate the three report Workflows. |
| `personal_weekly_report` | Prepare, submit or update a personal report. |
| `group_weekly_report` | Prepare group summaries without sending WeChat messages. |
| `tencent_weekly_report` | Prepare an approximately 100-character Tencent progress draft. |

Expand `weekly_report` in Abilities → Programs → Workflow to select an entry. Each child remains an independent Git package. Shared internal implementation is hidden from this list.
