# `openprogram/cli/`

Compatibility package for existing `openprogram.cli` imports and
`python -m openprogram.cli`. The Python CLI application is owned by
`apps/cli/python/openprogram_cli/`.

## Files in this directory

- **`__init__.py`** — resolves and loads the installed or source application
- **`__main__.py`** — preserves `python -m openprogram.cli`
- **`README.md`** — documents the compatibility boundary
