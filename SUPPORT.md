# OpenProgram Support

- Read the [documentation](https://openprogram.io/docs/) and
  [troubleshooting guide](https://openprogram.io/docs/server/troubleshooting.html).
- Ask usage and design questions in
  [GitHub Discussions](https://github.com/Fzkuji/OpenProgram/discussions/categories/q-a).
- Report reproducible bugs through the
  [issue tracker](https://github.com/Fzkuji/OpenProgram/issues/new/choose).
- Report suspected vulnerabilities privately through
  [Security Advisories](https://github.com/Fzkuji/OpenProgram/security/advisories/new).

Include the OpenProgram version or commit, operating system, Python version,
interface, provider, and a minimal reproduction. Remove credentials and private
data from logs before sharing them.
