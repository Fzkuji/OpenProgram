Your agent, ordinary Python

Use a decorated function for the task contract and call the model only where the workflow needs judgement.

@agentic_function
def triage(ticket: str, runtime=None):
    kind = runtime.exec(ticket,
        choices=["bug", "feature"])
    return handle(ticket, kind)
