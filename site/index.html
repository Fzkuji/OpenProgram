Open-source Python agent harness

Agents are just
Python functions.

OpenProgram keeps execution in ordinary Python and calls the model only where judgement is needed. The docstring defines the task, parameters carry input, and typed return values bring the result back into code.

triage.py 
@agentic_function
def triage(ticket: str, runtime=None) -> str:
    """Classify the ticket, then draft a reply."""
    kind = runtime.exec(ticket,
        choices=["bug", "feature", "question"])

    if kind == "bug":             # code decides
        logs = search_logs(ticket)    # plain Python
        return runtime.exec(
            f"Find the root cause:\n{logs}")

    return runtime.exec("Draft a short reply.")

Agentic Programming

One function carries the whole contract.

Model reasoning and deterministic code share the same variables, branches, loops, and error handling. No separate workflow DSL is required.

"""docstring"""

Task

The function documentation becomes the system instruction for the agent.

(ticket: str)

Input

Parameters define what enters the call and remain ordinary Python values.

runtime.exec(...)

Judgement

The model is invoked at the exact points where code cannot decide reliably.

-> str

Output

The result returns to typed control flow, ready for validation or another call.

Harness mechanisms

Context, control, and events stay explicit.

OpenProgram provides the runtime components needed for multi-agent work without moving the application into a separate orchestration language.

caller + reads

DAG Context

Every user turn, model call, and function call is a node. Context is selected from dependency edges, so branches, sub-agents, cross-session messages, and isolated worktrees share one execution model.

Agentic Workflow

Code fixes the required order, validates model decisions, and retries failed checks. Agentic functions can call other functions, use tools, and be loaded through the same Python runtime.

Event Infrastructure

A process-wide event bus carries activity from the agent loop, authentication, context, channels, and memory. Subscribers can observe typed events without coupling those systems together.
