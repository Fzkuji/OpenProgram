triage.py 
@agentic_function
def triage(ticket: str, runtime=None) -> str:
    """Classify the ticket as bug / feature /
    question, then draft a reply."""
    kind = runtime.exec(                    # agent classifies
        ticket, choices=["bug", "feature", "question"])
    if kind == "bug":                       # code branches
        logs = search_logs(ticket)          # plain Python
        return runtime.exec(                # agent finds root cause
            f"Find the root cause in these logs, "
            f"then draft a reply with a workaround:\n{logs}")
    return runtime.exec("Draft a short reply.")

Agentic Programming

One decorator. Ordinary code.

The @agentic_function decorator injects everything the agent needs into a plain function. Agent calls share variables, control flow, and scope with regular Python statements.

"""docstring"""

The docstring is the system prompt

Write what the agent should do where documentation already lives. The function signature carries the contract: parameters in, typed return value out.

kind = runtime.exec(...)

Output lands in a variable

An agent call is an expression. Its result flows into an if, a loop, an f-string, or the return value, like any other Python value.

triage(other_ticket)

Agents nest as functions

An agentic function calls other agentic functions the way functions call functions. Composition, recursion, and testing come from the language itself.

Context

Assembled from the execution DAG

Every agent call gets its context built automatically from the DAG of the running program: which function it is in, what values are in scope, and which calls led here. No hand-written prompt assembly.

Because each call sees only its own scope instead of the whole transcript, scoping takes cumulative token cost from quadratic growth toward log-linear.

O(n²) to O(n log n) is a theoretical estimate from the scoping structure, not a measured benchmark.
