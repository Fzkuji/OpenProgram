How it works

The model decides. Python makes sure the steps run.

An agent is a Python class. Branches, retries and checks are ordinary code, and self(...) is a model call.

support_agent.py
from openprogram import Agentclass SupportAgent(Agent):    def triage(self, ticket: str) -> str:        """Classify the ticket, then draft a reply."""        kind = self(ticket, choices=["bug", "question"])        if kind == "bug":            logs = search_logs(ticket)  # your own helper            return self(f"Reply using:\n{logs}")        return self("Draft a short reply.")

Highlighted lines are model calls. choices makes the model pick from a fixed menu.

  1. A graph, not a transcript

    Every turn, model call and function call is a node you can inspect, branch and replay.

  2. Agents that program themselves

    An agent writes new methods into its own class. From the next turn, each one is a tool it can call.

  3. Checked decisions

    Code validates the model's pick before anything runs, and sends a bad one back for another try.
