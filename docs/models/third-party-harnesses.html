Third-Party Harnesses

Settings → Third-Party Harnesses picks the model Claude Code and Codex on this computer run on, and shows what they use, read from the session files they keep.

PartShows
In a chatThe Harness chip before the model chip runs the conversation on Codex: its models, efforts, agents and permission modes replace OpenProgram's, its approvals appear in the chat, and codex resume <id> continues the same session in a terminal. It is the codex you installed; when a newer one is out, the model menu shows the models it adds and Update Codex
ModelsThe harness's own sign-in, or Through OpenProgram with any enabled model; for Claude Code also the model behind Opus, Sonnet and Haiku
Also in the TerminalWrites the choice into ~/.codex/config.toml or ~/.claude/settings.json, so codex and claude in a terminal use it too, and so does the Codex app, which lists the enabled models and picks up the change by itself. Turning it off puts the earlier values back. Config Changed Elsewhere means a value was edited since; it is left as it is.
A card per harnessSessions, tokens, output and the API estimate for the last 30 days
Codex planEach limit as a meter with its reset time and credits, as Codex last wrote them
Daily tokensOne bar per day, one colour per harness
SessionsTitle, folder, branch, models, the app that started it, tokens and estimate. Filter by harness or search; the copy button copies the command that continues the session in a terminal.
By model, Started fromTotals per model and per app (terminal, desktop app, an SDK)
API estimate
What the calls would cost at API list prices. It is not your subscription bill. A + means some calls used a model with no known price.
Claude plan quota
Not shown: Claude Code's files do not record it.
Files read
~/.claude/projects (or $CLAUDE_CONFIG_DIR) and ~/.codex/sessions, ~/.codex/archived_sessions (or $CODEX_HOME)
Through OpenProgram
The harness sends its model calls to the OpenProgram Worker, which must be running. The model's provider bills as usual, and the calls count in Token Usage.
Kept
92 days, also after Claude Code deletes its own old transcripts
Turn off
Read Claude Code and Codex sessions at the bottom of the page, or openprogram config set usage.third_party_harnesses false
