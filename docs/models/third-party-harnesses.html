Third-Party Harnesses

Settings → Third-Party Harnesses picks the model Claude Code and Codex on this computer run on, and shows what they use, read from the session files they keep.

PartShows
In a chatThe Harness chip before the model chip runs the conversation on Codex: its models, efforts, agents and permission modes replace OpenProgram's, its approvals appear in the chat, and codex resume <id> continues the same session in a terminal. It is the codex you installed; when a newer one is out, the model menu shows the models it adds and Update Codex
Other agentsClaude Code (also on any enabled model, picked in its model menu), DeepSeek Harness and Google's Gemini CLI run a conversation the same way, each with its own models and sign-in. Gemini CLI uses the Google login or Gemini API key you set up in it, else the Google API key in Model Services
ModelsThe harness's own sign-in, or Through OpenProgram with any enabled model; for Claude Code also the model behind Opus, Sonnet and Haiku and its subagents' model; for Codex its subagents' and memories' models and Background Compaction. Command Not Found means its settings folder is here but the command is gone
Editors and appsListed when installed, each with its model: VS Code, VS Code Insiders, VSCodium, Zoo Code, Zed, Antigravity, Dim, Kun, Nowledge Mem, OpenHanako, Alma, Shelley, miniQ. Cursor Private Inference and Avibe are a switch. Cindy, AionUi, Cherry Studio and Lody take a link: Add in … opens the app to confirm; Added shows once it has. Dim, Kun, Nowledge Mem, Alma, Shelley and Avibe must be open to change
More agentsCrush, Goose, Kimi Code, jcode, Mistral Vibe, AtomCode, Grok Build, Kigi, Grok App, Reasonix Studio, Mister Morph, Muse Code, PenguinHarness, Hermes Agent, Raycast, DeepSeek Harness and DS Bot get a Models row when they are on this computer. Through OpenProgram adds the enabled models to the agent's own model list and starts it on the one picked; its other providers stay, and going back to its own setup restores its files.
Their settingsWhere the agent has them, its effort or thinking level is picked below the model, Kimi Code's subagent pool takes several models at once, DeepSeek Harness also offers its own DeepSeek models, and Telemetry set to Off turns off the usage data it sends its own vendor, connected or not
Also in the TerminalWrites the choice into ~/.codex/config.toml or ~/.claude/settings.json, so codex and claude in a terminal use it too, and so does the Codex app, which lists the enabled models and picks up the change by itself. Turning it off puts the earlier values back. Config Changed Elsewhere means a value was edited since; it is left as it is.
More apps and CLIsClaude Desktop, Claude Science, T3 Code, OpenMausBot, Paseo, NewMax, MiniMax Code, ZCode and Kiro Crew, each a row when it is on this computer: pick a model and OpenProgram writes it into that app's own settings; turning it off puts them back. Claude Code's other config folders (~/.claude-work …) each get a row. NewMax and OpenMausBot must be closed while it is changed; Restart reopens an app that read its settings before
Claude Desktop beside yoursOn a Mac, Runs In makes Claude OpenProgram in ~/Applications: a copy on OpenProgram that runs beside your own signed-in Desktop
More agentsThrough OpenProgram works the same way, in each one's own config, for Qwen Code, Copilot CLI (its own providers), Command Code, fx, Empryo, nanobot, Paimon, Ante, Cline, Qoder and Qoder CN, Open Code Review, Snow CLI, Tuanjie Cowork, OpenPencil, WorkBuddy and WorkBuddy AI, CodeBuddy, Copilot in JetBrains IDEs, Droid, Obsidian (Copilot for Obsidian), AstrBot, OpenClaw and QwenPaw. An app that reads its settings only at start needs a restart; quit OpenPencil before turning it on
OpenCode and kinOpenCode, OpenChamber, MiMo Code, DevEco Code, JetBrains Air (app and IDEs) and OpenBot get Through OpenProgram written into their own config: the enabled models appear in their model picker, the chosen one is their default. In Air pick the OpenProgram agent; OpenBot lists the models in its own picker after a restart
Pi and kinPi, OmO, Prime Agent, mu, StepCode, Aside, Pencil, Craft Agents, MothX, LiveAgent and omp (each omp profile too) get Through OpenProgram written into their own config, with their thinking level; Pi and omp also the protocol their models are asked on, omp its roles and advisor, Aside which of its accounts. Pencil and LiveAgent list the models in their own picker; quit LiveAgent before changing it
Terminal-only agentsGemini CLI in a terminal can run on any enabled model too, while its chats here keep your own Gemini sign-in. Antigravity CLI (agy) can too: type agy in a new terminal; its card also picks its effort and turns Fast Tools on or off, even while agy isn't on OpenProgram. Cursor CLI and Devin only pick among their own models, Devin with an effort
A card per harnessSessions, tokens, output and the API estimate for the last 30 days
Codex planEach limit as a meter with its reset time and credits, as Codex's app-server last reported them
Daily tokensOne bar per day, one colour per harness
SessionsTitle, folder, branch, models, the app that started it, tokens and estimate. Filter by harness or search; the copy button copies the command that continues the session in a terminal.
By model, Started fromTotals per model and per app (terminal, desktop app, an SDK)
API estimate
What the calls would cost at API list prices. It is not your subscription bill. A + means some calls used a model with no known price.
Claude plan quota
Not shown: Claude Code's files do not record it.
Files read
~/.claude/projects (or $CLAUDE_CONFIG_DIR) and ~/.codex/sessions, ~/.codex/archived_sessions (or $CODEX_HOME)
Through OpenProgram
The harness sends its model calls to the OpenProgram Worker, which must be running. The model's provider bills as usual, and the calls count in Token Usage.
Kept
92 days, also after Claude Code deletes its own old transcripts
Turn off
Read Claude Code and Codex sessions at the bottom of the page, or openprogram config set usage.third_party_harnesses false
