第三方 Harness

设置 → 第三方 Harness 选择本机 Claude Code 和 Codex 使用的模型，并显示它们的用量，数据来自它们自己保存的会话文件。

部分显示
在对话里模型芯片前的 Harness 芯片让对话改由 Codex 运行：模型、思考档位、Agent 和权限模式换成 Codex 的，它的审批出现在对话里，终端里 codex resume <id> 能接着同一个会话。用的是你自己安装的 codex；有新版时，模型菜单会列出新版带来的模型和 Update Codex
其他智能体Claude Code（也可在它的模型菜单里选任一已启用的模型）、DeepSeek Harness 和 Google 的 Gemini CLI 也能这样运行对话，各用自己的模型和登录。Gemini CLI 用你在它里面设好的 Google 账号或 Gemini API 密钥，没有时用模型服务里的 Google API 密钥
模型Harness 自己的登录，或通过 OpenProgram 使用任一已启用的模型；Claude Code 还可分别指定 Opus、Sonnet、Haiku 背后的模型和子智能体的模型；Codex 可指定子智能体和记忆用的模型，以及后台压缩。找不到命令表示它的设置目录还在，但命令已不在
编辑器和应用装了就列出，各自选模型：VS Code、VS Code Insiders、VSCodium、Zoo Code、Zed、Antigravity、Dim、Kun、Nowledge Mem、OpenHanako、Alma、Shelley、miniQ。Cursor Private Inference 和 Avibe 是开关。Cindy、AionUi、Cherry Studio 和 Lody 用链接：在 … 中添加打开应用确认，有了之后显示已添加。Dim、Kun、Nowledge Mem、Alma、Shelley 和 Avibe 要开着才能修改
更多智能体Crush、Goose、Kimi Code、jcode、Mistral Vibe、AtomCode、Grok Build、Kigi、Grok App、Reasonix Studio、Mister Morph、Muse Code、PenguinHarness、Hermes Agent、Raycast、DeepSeek Harness 和 DS Bot 在本机时会出现在模型里。通过 OpenProgram 把启用的模型加进智能体自己的模型列表，并让它从所选模型开始；它的其他提供商不动，换回它自己的设置会还原它的文件
它们的设置智能体有的话，模型下方可选思考强度或思考档位，Kimi Code 的子智能体池可同时选多个模型，DeepSeek Harness 还可选它自己的 DeepSeek 模型，遥测设为关闭会关掉它发给自己厂商的使用数据，连接与否都生效
也用于终端把选择写进 ~/.codex/config.toml 或 ~/.claude/settings.json，终端里的 codex 和 claude 也用它，Codex 应用也一样：它会列出已启用的模型，并自动用上新的设置。关闭后恢复原来的值。配置已在别处修改表示之后有值被改过，它会保持原样。
更多应用和 CLIClaude Desktop、Claude Science、T3 Code、OpenMausBot、Paseo、NewMax、MiniMax Code、ZCode 和 Kiro Crew 在本机时各占一行：选一个模型，OpenProgram 就把它写进那个应用自己的设置；关闭后恢复原样。Claude Code 的其他配置目录（~/.claude-work …）各占一行。修改时 NewMax 和 OpenMausBot 须先退出；重启会重新打开读过旧设置的应用
和你的 Claude Desktop 并排在 Mac 上，Runs In（运行位置）会在 ~/Applications 里建一个 Claude OpenProgram：一份跑在 OpenProgram 上的副本，和你自己已登录的 Desktop 并排运行
更多智能体通过 OpenProgram 同样适用于下列智能体，写进各自的配置：Qwen Code、Copilot CLI（它自己的提供商）、Command Code、fx、Empryo、nanobot、Paimon、Ante、Cline、Qoder 和 Qoder CN、Open Code Review、Snow CLI、Tuanjie Cowork、OpenPencil、WorkBuddy 和 WorkBuddy AI、CodeBuddy、JetBrains IDE 里的 Copilot、Droid、Obsidian（Copilot for Obsidian）、AstrBot、OpenClaw 和 QwenPaw。只在启动时读设置的应用需要重启；接入 OpenPencil 前先退出它
OpenCode 及同类OpenCode、OpenChamber、MiMo Code、DevEco Code、JetBrains Air（应用和 IDE）和 OpenBot 会把通过 OpenProgram写进它们自己的配置：已启用的模型出现在它们的模型选择器里，选中的就是默认模型。在 Air 里选 OpenProgram 智能体；OpenBot 重启后在自己的选择器里列出这些模型
Pi 及同类Pi、OmO、Prime Agent、mu、StepCode、Aside、Pencil、Craft Agents、MothX、LiveAgent 和 omp（包括 omp 的每个 profile）会把通过 OpenProgram写进它们自己的配置，连同思考档位；Pi 和 omp 还可选模型走的协议，omp 还有各角色和 advisor，Aside 还可选写哪个账户。Pencil 和 LiveAgent 在自己的模型选择器里列出这些模型；改 LiveAgent 前先退出它
只在终端用的智能体终端里的 Gemini CLI 也能用任一已启用的模型，这里的 Gemini CLI 对话仍用你自己的 Gemini 登录。Antigravity CLI（agy）也可以：在新终端里输入 agy 即可；它的卡片还能选推理强度、开关 Fast Tools，agy 没接 OpenProgram 时也能开关。Cursor CLI 和 Devin 只能在它们自己的模型里选，Devin 还能选推理强度
每个 Harness 一张卡片最近 30 天的会话数、Token、输出和按 API 价估算的费用
Codex 套餐每项额度一条进度条，带重置时间和 credits，取 Codex app-server 最近一次报告的值
每日 Token每天一根柱，每个 Harness 一种颜色
会话标题、文件夹、分支、模型、启动它的应用、Token 和估算费用。可按 Harness 筛选或搜索；复制按钮复制在终端里继续这个会话的命令。
按模型、启动来源按模型和按应用（终端、桌面版、SDK）的合计
按 API 价估算
这些调用按 API 标价算的费用，不是订阅账单。带 + 表示部分调用的模型没有已知价格。

读取的文件
~/.claude/projects（或 $CLAUDE_CONFIG_DIR），以及 ~/.codex/sessions、~/.codex/archived_sessions（或 $CODEX_HOME）
通过 OpenProgram
Harness 把模型调用发给 OpenProgram 的 Worker，Worker 需要在运行。模型所属的提供商照常计费，这些调用计入 Token 用量。
