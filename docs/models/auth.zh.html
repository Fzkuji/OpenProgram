认证

OpenProgram 要求安全、合法、合规地使用 Anthropic 服务：官方 API、合法获取的 API 密钥、按 API 账户计费，所有调用遵守 Anthropic 的服务条款和使用政策。

存放位置

~/.openprogram/auth/<provider>/<account>.json，权限 0600。用 --profile <name> 时根目录是 ~/.openprogram-<name>/。

运行时只读凭据库。环境变量里的密钥要先导入，之后改变量不影响已导入的凭据。例外，运行时自动检测：Amazon Bedrock（AWS_PROFILE、访问密钥、bearer token 等）和 Google Vertex（ADC）。

来源

来源方式
API 密钥openprogram providers login deepseek，或 printf %s "$KEY" | openprogram providers login deepseek --api-key-stdin。--api-key 也可用，但会留在 shell 历史里。
Anthropicopenprogram providers login anthropic，再输入 Anthropic API 密钥

login 自动选择方式；--method 可强制指定。

订阅

ChatGPT 或 Claude 套餐，通过把厂商自己的程序作为外部 Agent 运行来使用：第三方 Harness。OpenProgram 自己不登录任何套餐（原因）。

从本机导入

openprogram providers discover        # 只列出，不写入
openprogram providers adopt qwen_cli  # 导入一项；--all 导入全部

环境变量OPENAI_API_KEY、ANTHROPIC_API_KEY 等对应的 Provider

外部 CLI 还在时存一个指针，每次调用重读其文件。否则复制 token，由 OpenProgram 刷新。

辅助命令

适用于由 aws、sso-helper、token-fetcher 这类 CLI 签发的 token：在设置 → 模型服务 添加类型 credential_process。

字段含义默认
commandargv 列表，不经 shell 运行必填
parsesjson，或 text 取去空白的 stdoutjson
json_key_path逐层取键，如 ["creds", "token"]。为空时整个文档必须是字符串[]
cache_secondstoken 复用时长。0 每次调用都运行300
timeout_seconds单次运行上限60

登录冒烟测试会运行一次。失败（非零退出、超时、输出无法解析、缺键路径）时请求失败并给出命令和 stderr，绝不回退到其他凭据。修好辅助命令，或删除它改用其他来源。

企业 SSO（sso）未实现；API 和解析器都会拒绝。

管理

命令见配置模型。

一个 Provider 的 key 和登录组成一个有序列表。对话一直用开始时的 key；它被限流、额度用完或被拒时换到下一个可用的，回复里显示一行提示。

策略：in-order（默认，用第一个可用的）、evenly、least-used。对话可以固定用某一个 key：使用多个密钥。

openprogram providers keys openai list
openprogram providers keys openai add --name work
openprogram providers keys openai move work --to 1
openprogram providers keys openai strategy evenly
