# 查看和编辑 Memory

打开 **History → Memory**，再选择一个主题。文档默认显示预览，包括 Markdown
排版和来源脚注。选择“编辑”修改源文本。Core 源记录使用同一个编辑器；Core
提示词预览显示当前可用于注入的内容。

停止输入 800 毫秒后会自动保存，离开文档时也会开始保存待提交的修改，不需要
Save 按钮。尚未保存的草稿会保留在当前浏览器的本地存储中，切换页面或重新加载
后仍可恢复。如果本地草稿存储不可用且尚未保存成功，请保持页面打开。

“本次修改”比较当前内容与本次编辑开始时载入的内容，包括已经自动保存的修改。
“历史”按从新到旧的顺序列出 Git 版本，显示本地日期和时间。选择一个版本即可
查看该次修改增加和删除了哪些行。“加载更早版本”可以继续查看旧记录。

保存时会校验来源引用、重建 Memory 派生视图，并创建 Git 提交。未通过校验的
修改会保留在编辑器中，并显示被拒绝的原因。如果文件已保存但 Git 留档失败，
页面会单独显示该错误。

如果其他写入者修改了同一文件，自动保存会拒绝覆盖。点击“查看最新版本”比较
最新已保存内容与当前草稿。“用当前草稿替换最新版本”会以刚查看的版本为基础
重新保存；如果此时又有其他修改，仍会拒绝覆盖。
