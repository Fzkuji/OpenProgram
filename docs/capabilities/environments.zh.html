在另一台机器上运行会话

机器是 OpenProgram 能连到的任何电脑。项目是某台有 Shell 的机器上的一个文件夹，项目里的每个会话都在那台机器的那个文件夹里运行。

运行环境命令在哪运行文件在哪读写
这台电脑（始终存在）这台电脑这台电脑
SSH 主机远程主机上项目的文件夹远程主机
Docker 容器这个会话专属的容器这台电脑；项目的文件夹按相同路径挂载进容器

渠道只决定消息镜像到哪里，绑定渠道不会改变工具运行的位置。

在机器上打开项目

  1. 在新会话里打开顶栏的项目菜单，选在…上打开文件夹；或在项目页选添加项目文件夹…。
  2. 选机器。未连接的机器显示为灰色；添加设备…打开设置 → 设备。
  3. 选文件夹。这台电脑和 Docker 机器用平常的文件夹选择器。SSH 主机打开它的文件夹浏览框，从它的远程文件夹开始；可以输入路径或点进子文件夹。

项目菜单按机器分组列出项目，这台电脑在最前。主项目总在这台电脑上。消息框上方的机器按钮显示项目的机器，在那里不能切换，因为由项目决定。要在另一台机器上运行，就在那台机器上打开项目。

机器图标旁的点含义
绿色已连接
转圈连接中
灰色已关闭
红色连不上

侧栏里，另一台机器上的项目在项目名旁显示那台机器的图标、点和名称。

添加机器

在设置 → 设备，或在终端。每台机器有测试、编辑、删除和一个开关。openprogram setup 有 Machines 步骤。

命令作用
openprogram machines add devbox --name "Dev box" ssh target=me@devbox workdir=~/worktarget 是 user@host 或 ~/.ssh/config 里的主机名。workdir 是绝对路径或 ~ 路径；留空为远程 home。22 端口上的这台电脑会被拒绝；换成别的端口，如 ssh://me@127.0.0.1:2222，连到的是端口转发过来的虚拟机或容器。
openprogram machines add sandbox docker image=python:3.12默认镜像 ubuntu:24.04
openprogram machines list --kinds列出全部机器（含已关闭的）；--kinds 另列出每种连接方式及其设置
openprogram machines test devbox检查机器能否响应
openprogram machines disable devbox关闭它：它上面的项目变灰、不能开新会话，这些会话下一条命令和文件调用报错停止，命令返回之前它的容器连同其中的文件被删除。在设置里关闭时，先让已经在运行的命令结束（最多 5 分钟），其间重新打开则保留它的容器。enable 重新打开。
openprogram machines remove devbox删除，过程相同

ID 由小写字母、数字、- 或 _ 组成，不会改变；只能改名称。旧配置里的 environments 部分不再读取：请把那些地方重新添加为机器。

每台机器只有一种连接方式，它决定这台机器用来做什么。SSH 主机和 Docker 容器跑命令。OSWorld 虚拟机（openprogram machines add lab osworld url=http://192.168.64.2:5000）给操控电脑提供它的屏幕。

另一台电脑的 OpenProgram 通过配对添加，它的对话显示在这里、在那边运行。那边打开允许已配对设备操作这台电脑后，操控电脑还能操作它的窗口、整屏和浏览器。

要求

需要与行为
SSH 登录系统 ssh 加 BatchMode=yes：不能有任何提示。使用 SSH agent 或 ~/.ssh/config 已提供的密钥。新主机密钥首次接受，之后校验。连接共享五分钟。
SSH 主机POSIX shell、find、grep；安装了 rg 时使用
Dockerdocker 在 PATH 上，daemon 正在运行
Docker 容器每个会话一个，名为 openprogram-<machine>-<conversation>。第一条命令启动，后续复用，安装的包保留。Docker 重启、docker stop 或手动删除之后，下一条命令会重新启动它。会话文件夹变化时重建。会话被删除时（单独删除或全部清除）连同其中的文件移除，机器被删除或关闭时也移除。共用同一个 Docker 的另一套 OpenProgram 安装保留自己的容器。

限制

  • 一轮的撤销不覆盖 SSH 主机上改动的文件；这台电脑上的文件仍会恢复。
  • SSH 主机上的项目没有 git 标签、工作树、自动提交和在文件管理器中显示；文件面板和 @ 文件搜索读的是主机上的文件夹。
  • 在 SSH 主机上文件必须先读取再编辑；读取后主机上有变化时，编辑被拒绝。
  • 本地沙箱只作用于这台电脑。SSH 和 Docker 的权限是远程账号或容器的权限。
  • 机器被删除或关闭后，即使在回合中途，会话的下一条命令或文件调用也会报错停止，绝不回退到这台电脑。用相同 ID 加回来、重新打开，或在另一台机器上打开项目的文件夹。
