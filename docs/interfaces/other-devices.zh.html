在其他设备上使用 OpenProgram

  1. 添加设备设置 → 设备：选择它是什么
  2. 扫码或粘贴一次性代码，10 分钟内有效
  3. 已登录直到你吊销它，或它 30 天没有使用

对话、文件和账号都留在运行它们的那台电脑上。手机或浏览器显示的是那台电脑的 OpenProgram；另一台电脑的 OpenProgram 则在自己的列表旁列出它的对话，并把你的操作发到那里。所有设备，不论手机还是服务器，都在设置 → 设备的同一个列表里。

添加设备

设备怎么做
手机或平板用相机扫二维码，会在它的浏览器里打开 OpenProgram，并且已经登录。
另一台装了 OpenProgram 的电脑在这里看它的对话：粘贴它给出的链接。让它用这台：这台电脑给出链接，粘贴到那边。
SSH 服务器从 SSH 配置里选一台主机，或输入 user@host。添加后先测试连接。
其他设备用一句话描述它。会打开一个填好请求的新对话；智能体自己查参数，添加并测试设备。

代码只能用一次，显示期间会自动换新。如果还没有任何方式能连到这台电脑，添加设备时会先问从“同一 Wi-Fi”还是“任何地方”连；二维码下面各有一行显示它开没开，没开的可以在那里直接打开。

从哪里打开这台电脑

从哪里能连怎么设置
同一 Wi-Fi这个网络里的手机和电脑；不加密，只在信任的网络上使用打开开关，立即生效
任何地方任何网络，走 https打开开关，在浏览器里登录一次 Tailscale。Tailscale 已内置在 OpenProgram 里：这台电脑和手机上都不用另外安装

能连到地址并不能直接登录：每台设备都要先用代码添加。链接里带着所有已打开的地址，对方会依次尝试，所以笔记本离开家后照样能用。

在手机上

  1. 打开链接扫二维码，通过“任何地方”
  2. 添加到主屏幕分享 → 添加到主屏幕；Chrome：安装应用
  3. 打开通知设置 → 通用 → 通知

从主屏幕打开时，OpenProgram 像应用一样占满屏幕。对话在等你、回复好了、对话出错停下时，这台电脑会发通知，每一类都能单独关掉。

点通知会打开那个对话。通知只说是哪类事情，不含对话内容。通知需要“任何地方”：通过“同一 Wi-Fi”打开的手机能用 OpenProgram，但收不到通知。

界面手机上
对话列表点左上角按钮，或从屏幕左边缘向右滑；点旁边或向左滑关上
文件、活动、资源点标签行最右的按钮，整屏打开
设置、历史先是分区列表，点一项进入，左上的返回箭头回到列表
输入框键盘弹出时停在键盘上方

另一台电脑的对话

操作结果
打开、发送、停止、确认在那台电脑上进行，用它的模型、工具和文件
在它的项目里新建对话在那里创建和运行
它离线它的项目仍在列表里，显示红点，打开时什么都没有，直到它回来；没有复制任何东西可显示

这台电脑的权限

在列表里点这台电脑，可以看到 OpenProgram 在这里能使用哪些权限。点打开会跳到系统设置里对应的位置，下面出现一个小窗口，显示要拖进列表的应用；打开后这一行会自动变成已打开。控制其他应用和打开文件，由 macOS 在第一次用到时询问。

吊销与命令行

在设备的菜单里点吊销，它会立即退出，连接随之关闭。在终端里也可以：

命令作用
