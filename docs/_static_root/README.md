# openprogram-site

Published build of [openprogram.io](https://openprogram.io) — the OpenProgram
documentation site.

Everything in this repository is generated. The sources live in
[Fzkuji/OpenProgram](https://github.com/Fzkuji/OpenProgram) under `docs/`, and a
workflow there rebuilds and force-pushes this branch whenever the documentation
changes. Edit the docs in that repository; edits made here are overwritten by
the next publish.
