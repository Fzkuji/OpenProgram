A release holds each file once, under its versioned name. These links download that file from the newest release, and open its release page when they cannot. A macOS or Windows build with no publisher signature adds -unsigned to the name. The terminal archives, OpenProgram-X.Y.Z-runtime-…, are on the newest release page; the terminal install downloads the right one for you.
