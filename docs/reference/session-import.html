Credentials

Sign-in files (~/.claude/.credentials.json, ~/.codex/auth.json) are never read. Inside transcripts, provider keys, GitHub, Slack, AWS and Google tokens, JWTs, private keys, Bearer … and password=… values, and tool arguments named like api_key or token become [secret removed], in titles and in the listing's cache as well. The original transcripts are not changed.
