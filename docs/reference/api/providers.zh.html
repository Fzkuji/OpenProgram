API key 存在凭据库：设置 → 模型服务，或 openprogram providers login <provider> --api-key。Anthropic、OpenAI、Google SDK 是基础依赖；其余 provider 直接走 HTTP。

函数

函数行为
create_runtime(provider=None, model=None, **kwargs)返回可用的 Runtime。None 或 "auto" 运行 detect_provider()。**kwargs 转给构造函数。每个 runtime 都有权威的 provider_id。
detect_provider() -> (name, default_model)顺序见下。找不到时抛 RuntimeError 并给出配置指引。
check_providers() -> dict三个专用 provider 的 {name: {"available": bool, "method": "API", "model": default}}；"default": True 标记检测会选中的那个
 
from openprogram.models.providers.catalog.registry import detect_provider, check_providers

检测顺序

  1. 环境变量：AGENTIC_PROVIDER / AGENTIC_MODEL
  2. ~/.openprogram/config.json → last_used_model
  3. 已存 API key：anthropic → openai → google

API key 服务商

rt = create_runtime(provider="anthropic", api_key="sk-ant-...", model="claude-sonnet-4-6")
rt = create_runtime(provider="openai", api_key="sk-...", model="gpt-4.1")
rt = create_runtime(provider="gemini", api_key="...", model="gemini-2.5-flash")
参数默认值含义
api_keyNonestr | None；给定的 key 原样发送。None 让每次请求从 provider 的 key 和登录列表中选择，被限流或被拒时换下一个；一个都没有时抛 ValueError。
model见上表provider 命名空间下的 id（anthropic、openai、google）
max_retriesOPENPROGRAM_MAX_RETRIES，否则 6转给基础 Runtime 的重试额度
provider接口说明
anthropicAnthropic Messageslist_models() 返回已启用模型 id
openaiOpenAI ResponsesAzure 或本地 OpenAI 兼容服务：添加自定义 provider
geminiGoogle Generative Language添加 key 时接受的环境变量名：GEMINI_API_KEY、GOOGLE_API_KEY、GOOGLE_GENERATIVE_AI_API_KEY

都包含流式、工具循环和 DAG 记录。自定义 provider：设置 → 模型服务 → 添加自定义 provider（名称和 base URL），然后 Runtime(model="<provider>:<model>") 或 create_runtime(provider="<provider>")。只有主机的 base URL 解析为 /v1；显式 API 路径保留。

自定义 Provider

from openprogram.runtime.agent.runtime import Runtime

class MyRuntime(Runtime):
    def __init__(self, api_key, model="my-model"):
        super().__init__(model=model)
        self.api_key = api_key

    def _call(self, content, model="default", response_format=None):
        texts = [b["text"] for b in content if b["type"] == "text"]
        return my_api_call("\n".join(texts), model=model)

_call() 接收 content: list[dict]，返回 str。Runtime(call=fn) 无需子类也能达到同样效果。
