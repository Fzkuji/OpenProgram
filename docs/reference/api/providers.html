API keys live in the credential store: Settings → Model Services, or openprogram providers login <provider> --api-key. The Anthropic, OpenAI and Google SDKs ship as base dependencies; the rest talk raw HTTP.

Detection order

  1. Environment: AGENTIC_PROVIDER / AGENTIC_MODEL
  2. ~/.openprogram/config.json → last_used_model
  3. Stored API keys: anthropic → openai → google

All include streaming, the tool loop and DAG recording. Custom provider: Settings → Model Services → Add custom provider (name and base URL), then Runtime(model="<provider>:<model>") or create_runtime(provider="<provider>"). A host-only base URL resolves to /v1; an explicit API path is preserved.

Subscriptions

No runtime signs in to a ChatGPT or Gemini plan. A plan runs through the vendor's own program as an outside agent (Third-Party Harnesses); why.

Every other provider

from openprogram.runtime.agent.runtime import Runtime
rt = Runtime(model="deepseek:deepseek-chat")
# or
rt = create_runtime(provider="deepseek", model="deepseek-chat")

deepseek, groq, openrouter, minimax, kimi and the rest of the catalogue go through the model registry, the path the chat dispatcher uses. With no model and none registered, ValueError: enable some in Settings → Model Services or see openprogram providers available <provider>.

Custom providers

from openprogram.runtime.agent.runtime import Runtime

class MyRuntime(Runtime):
    def __init__(self, api_key, model="my-model"):
        super().__init__(model=model)
        self.api_key = api_key

    def _call(self, content, model="default", response_format=None):
        texts = [b["text"] for b in content if b["type"] == "text"]
        return my_api_call("\n".join(texts), model=model)

_call() takes content: list[dict] and returns str. Runtime(call=fn) does the same without a subclass.
