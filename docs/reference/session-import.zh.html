设置了 $CLAUDE_CONFIG_DIR 时从那里读 Claude Code，设置了 $CODEX_HOME 时从那里读 Codex。

导入哪些内容

部分规则
标题该 agent 显示的名字：改过的标题，其次是它生成的标题，再次是第一条消息
消息你输入的内容，以及每次回复的正文、思考、工具调用和结果，保留原来的时间
模型记在每条回复上
文件夹对话放进它运行时所在文件夹的项目，没有就新建；主目录或已不存在的文件夹放进默认项目
Claude Code 中回退过的轮次只取你最后看到的那条分支
不导入系统提醒、环境和 AGENTS.md 上下文、子 agent 的对话、没有回复的对话

凭据

从不读取登录文件（~/.claude/.credentials.json、~/.codex/auth.json）。对话里的服务商密钥，GitHub、Slack、AWS、Google 令牌，JWT，私钥，Bearer … 和 password=… 的值，以及名为 api_key、token 这类的工具参数，都替换成 [secret removed]，标题和列表缓存里也一样。原对话文件不改动。

再次导入

上次导入之后结果
没有新内容跳过，不写入
有新消息追加到同一个对话
在原 agent 里回退过，或在这里继续过新建一个对话；已有内容不被改写
导入的对话在这里被删除重新作为新对话导入

其他 App 里的对话

Codex App 和 Codex CLI、Claude App 的 Code 标签页、DeepSeek Harness 里的对话不用导入：它们自己出现在侧边栏和历史页里（“来源”筛选可只看一个 App），之后在 App 里说的也会同步过来。Codex 的对话行尾带 Codex 标。

想要做法
继续在 Codex 里聊直接发：接着同一个 Codex 线程，App 里也看得到新的轮次
接着聊 Claude 或 DeepSeek Harness 的对话直接发：在 OpenProgram 里继续；App 里保留它自己的那份
搬到 OpenProgram 聊把 Harness 芯片切到 OpenProgram，行尾的标消失。之后在 App 里说的仍会同步过来
