Occupancy and compaction

Ring, panel and compaction report read one view: what the model receives next turn. Compaction does not move HEAD, so an unchanged HEAD does not mean an unchanged graph.

The window

The denominator is the context window of the model the request ran on: the same number compaction reads for the same Model. It is resolved each time it is shown and never read back from a saved record.

Compaction outcomes

  1. Prepare: build the prompt from rendered history, calculate budget_pct.
  2. Compact at 80%: the model writes a summary, a summary node is appended.
  3. Prepare again: the request reads summary and tail.

System messages

Automatic and manual compaction share one branch in chat-handlers.ts. Messages are bilingual.

EventText
StartedNo message: the run indicator shows "Compacting context…"
FinishedNo message. The transcript reloads with the summary card (Compacted N earlier messages, with its time) folding the covered messages, on a branch that holds the whole covered segment; a branch forked inside it was never compacted. Nothing marks the point where the compaction ran: a line there repeats the card and puts token counts between two messages of the conversation. The panel states the last compaction instead
FailedContext compaction failed[: error]
Finished with no_opContext unchanged; no smaller summary was applied.

Acceptance

  • After success, ring and panel totals drop and match compaction_finished.tokens_after.
  • Re-compacting does not call the summary model and reports nothing to compact, never "covered 0 messages, X → X".
  • No suggestion border at any occupancy.
  • The ring's limit equals real_context_window of the Model compaction uses, for a chat with its own model and for one that follows its Agent, during a turn and after reload.
  • A branch with its own model shows that model's window when it is selected and when its tip is read while another branch is selected.
  • After the model changes to one with no known window, the terminal bar shows no limit.
  • During compaction the ring is busy and the button disabled; completion restores both.
