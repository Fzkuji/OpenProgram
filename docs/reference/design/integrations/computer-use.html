结论组件OpenProgram 处理
直接使用Microsoft Playwright MCP、Playwright、MCP SDK开源依赖；固定版本后接入。
直接调用接口CDP、Electron webContents.debugger、Chrome debugger / Native Messaging不需要复制 Claude 代码；内置浏览器直接使用 Electron/CDP，不需要另装 Chrome 扩展。
自行实现Claude 的 computer 工具实现、claude-in-chrome bridge、扩展 action handler、视觉光标与权限 UI只有公开行为和已发布产品，没有可复用的开源实现；按公开接口 clean-room 实现。
