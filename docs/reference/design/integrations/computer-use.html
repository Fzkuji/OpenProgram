系统结构

三个 backend 都是可选执行路径；Runtime 在 ComputerSession 创建时固定其中一个，并把所有动作限制到同一个 Page。

四个网页在一个窗口里怎样表示

目标返回结构是 tab_entries + pages。当前实现已经能返回四个独立 Page 并控制前台或后台目标，但仍只返回扁平 pages[]；分组字段尚未实现。完整字段见多 Page 数据模型。

Chat 渲染稳定性

存在 live normal assistant reply 或对应 runtime card 已存在时，Computer Use 的 tree update 不得触发 transcript reload。standalone run 缺少 persisted runtime card 时允许首次单次 hydrate。该约束确保已有历史 message element identity 保持不变，避免流式回复、滚动位置和消息操作状态被重置。
