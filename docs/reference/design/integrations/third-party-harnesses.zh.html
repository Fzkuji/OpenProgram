第三方 Harness

Claude Code 和 Codex 把每个会话写进本机文件。OpenProgram 读这些文件，显示会话、Token、估算费用和它们最近记下的套餐额度。

读取不改任何 Harness 的配置，不在请求路径上，也不向任何地方发送。让 Harness 使用 OpenProgram 的模型见模型网关。

读哪些文件

Harness读取
Claude Code$CLAUDE_CONFIG_DIR 或 ~/.claude：projects/<folder>/<session>.jsonl，以及 <session>/subagents/ 下除工作流 journal.jsonl 外的每个 *.jsonl

首次扫描跳过最后修改超过 92 天的文件。经链接重复到达的同一目录只读一次。

只读追加的内容

标记
每个文件记下大小、修改时间、最后一个完整行之后的偏移量，以及偏移量前 64 字节的哈希。
续读
文件变大且那 64 字节未变，就从偏移量读；变小或改变则从头读。
半行
没有换行符的最后一行等下次扫描。
压缩包
zstd 压缩包整份读取，大小或时间变了才再读。
标识
只解析含标识（"usage"、token_count、标题记录）的行，工具输出和图片按字节跳过。
时机
Worker 启动时在后台扫描；页面请求且上次扫描超过 5 秒时再扫；同一时间只扫一次。打开的页面每 10 秒请求一次。

在这台电脑上，首次扫描 8.6 GB 的 Claude Code 文件和 4.7 GB 的 Codex 记录用了 37 秒；之后一次 0.04 秒，30 天报表 0.2 秒。

每次调用只算一次

Harness一次调用是
Claude Code带 message.usage 的 assistant 行，键为 message.id + requestId。Claude Code 在每个内容块上重复用量，并把行复制进恢复和分叉的会话；副本对每种 Token 取最大值、时间取最早。模型 <synthetic> 不算调用。
Codex一条 token_usage_record，键为它的 response_id。没有这种记录的文件统计每个 token_count 的 last_token_usage，跳过累计值未变的，键为时间和大小，这样分叉复制的历史只算一次。
Token
无缓存输入、缓存读、缓存写（Claude 分 5 分钟和 1 小时）、输出。Codex 输入为 input − cached − cache_write；推理含在输出里。
模型
Claude message.model；Codex turn_context.model。
速度
Claude usage.speed；Codex service_tier 为 priority 或 fast。
应用
Claude entrypoint（cli、claude-desktop、sdk-ts 等）；Codex session_meta.originator。用来区分人自己跑的会话和别的应用通过 SDK 驱动的会话。

价格

费用是这些调用按 API 标价计算的值，标为按 API 价估算，不是订阅账单。价格在页面请求时套用，在 SQL 里按模型、速度和档位分组，所以价格目录更新后历史会重新定价，无需重扫。

规则价格
基础每百万 Token 的输入、输出、缓存读、缓存写价格
1 小时缓存写输入价的两倍，仅 Anthropic 模型（magpie 曾把这条规则误用到 OpenAI 模型上）
长上下文一次提示（输入 + 缓存读 + 缓存写）超过模型档位时，所有 Token 按该档计价
Fast模型的 fast 价格
未知模型Token 计入，费用不计；合计显示为 $12.40+。绝不按相似名称定价。

页面
