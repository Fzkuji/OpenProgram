Third-Party Harnesses

Claude Code and Codex write every session to files on this computer. OpenProgram reads those files and shows the sessions, tokens and estimated cost, plus the Codex plan quota its app-server last reported.

Reading changes no harness's configuration, sits in no request path and sends nothing anywhere. Running a harness on OpenProgram's models is the Model Gateway.

Which files

HarnessRead
Claude Code$CLAUDE_CONFIG_DIR or ~/.claude: projects/<folder>/<session>.jsonl, and every *.jsonl under <session>/subagents/ except a workflow's journal.jsonl
Codex$CODEX_HOME or ~/.codex: rollout-*.jsonl and rollout-*.jsonl.zst under sessions/ and archived_sessions/; names from session_index.jsonl

The first scan skips files last changed more than 92 days ago. A home reached twice through a link is read once.

Reading only what was appended

Mark
Per file: size, modification time, the offset after its last complete line, and a hash of the 64 bytes before that offset.
Resume
A file that grew and whose 64 bytes still match is read from the offset; one that shrank or changed is read from the start.
Partial line
A last line without its newline waits for the next scan.
Archive
A zstd archive is read whole, and again only when its size or time changes.
Markers
A line is parsed only when it holds a marker ("usage", token_count, a title record), so tool output and images are skipped as bytes.
Timing
The Worker scans at start, in the background, and again when the page asks and the last scan is older than 5 seconds; one scan at a time. The open page asks every 10 seconds.

On this computer the first scan, 8.6 GB of Claude Code files and 4.7 GB of Codex rollouts, took 37 seconds; the next took 0.04 seconds, and a 30-day report 0.2 seconds.

Counting each call once

HarnessOne call is
Claude CodeAn assistant line with message.usage, keyed message.id + requestId. Claude Code repeats the usage on each content block and copies lines into resumed and forked sessions; copies keep the largest value of each token kind and the earliest time. Model <synthetic> is not a call.
CodexA token_usage_record, keyed by its response_id. A file without them counts each token_count's last_token_usage, skipping one whose running total did not move, keyed by its time and size so a fork's copied history counts once.
Tokens
Input without cache, cache read, cache write (5-minute and 1-hour apart for Claude), output. Codex input is input − cached − cache_write; reasoning is inside output.
Model
Claude message.model; Codex turn_context.model.
Speed
Claude usage.speed; Codex service_tier priority or fast.
App
Claude entrypoint (cli, claude-desktop, sdk-ts, …); Codex session_meta.originator. It tells sessions a person ran from sessions another app drove through an SDK.

Price

The cost is the calls at API list prices, labelled an API estimate: it is not the subscription bill. Prices are applied when the page asks, grouped in SQL by model, speed and tier, so a catalogue update reprices history without a rescan.

RulePrice

The page

Settings → Third-Party Harnesses (/settings/harnesses), beside Token Usage and apart from it, so a harness's cost never enters OpenProgram's own totals or budgets. It was chosen over a source switch on Token Usage because it puts the harnesses side by side.
