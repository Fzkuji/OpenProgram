Tasks page

Work that runs without the user has two ends, what is set to run and what came back, and they share one page.

Reference: Codex's Automations, which keeps the scheduled automations and their results needing review under one entry.

Scheduled tab layout
  • Shared page header and theme tokens; ManageRow rows keep schedule, status and actions, numbered in visible order.
  • The type filters sit in a row below the header, no sidebar; they wrap when narrow.
  • Empty state: introduction and Create task centered; three suggestion cards in a centered grid up to 960px, one column when narrow, each with title, schedule, prompt and Use.
  • Create and Use open the existing form without creating a task; Escape returns.
