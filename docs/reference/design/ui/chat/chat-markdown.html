Markdown in Chinese

CommonMark was written for languages that put a space between words. Chinese does not, and models writing Chinese break its rules in a few fixed ways, so the marks show as text. Every renderer adds the same extensions to marked (lib/markdown/prose.ts); each takes only what the stock rules leave as text.

Rules

PartRule
Emphasis*, **, ***, ~~: taken when punctuation touches the inside of a mark, a non-space its outside, and CJK is on one side. _, __: taken when CJK touches the outside and the text inside has CJK, so snake_case stays (cjk-emphasis.ts)
Bare addressesEnd at the first full-width punctuation mark, and at CJK still in the host name. CJK in a path stays: zh.wikipedia.org/wiki/中文 (cjk-links.ts)
Link targetsFull-width parentheses count when the target is an address or a local path. A root, home, file:// or drive path may have spaces (spaced-path-links.ts)
MarkersA line starting with #–######, 1., 1), - or + directly followed by CJK is read with the space put back. Block tokens, so code is never touched (cjk-blocks.ts)
FormulasLexer tokens that render as .md-math holding their source; KaTeX draws only those and never scans text. $ opens before a non-space; the closing $ follows a non-space and is not followed by a digit, as in Pandoc. \(…\), \[…\], $$…$$ always count (math.ts)
