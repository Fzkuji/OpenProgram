中文 Markdown

CommonMark 是为词与词之间有空格的语言写的。中文没有空格，模型写中文时会以几种固定方式违反它的规则，于是标记显示成了文字。所有渲染入口都给 marked 加同一组扩展（lib/markdown/prose.ts），每个扩展只接手原规则会留成文字的写法。

##标题、1.第一项、-第一项标记显示成文字标题、列表
价格 $5，折后 $3从 $5 到 $ 成了一个公式文字

规则

部分规则
强调*、**、***、~~：标点贴着标记内侧、非空白贴着外侧、且一侧是中日韩字符时接手。_、__：外侧贴着中日韩字符且内部含中日韩字符时接手，所以 snake_case 不变（cjk-emphasis.ts）
裸网址在第一个全角标点处结束；主机名里出现中日韩字符也在那里结束。路径里的中文保留：zh.wikipedia.org/wiki/中文（cjk-links.ts）
链接目标目标是网址或本地路径时，全角括号也算。根目录、主目录、file:// 或盘符路径可以带空格（spaced-path-links.ts）
标记行首是 #–######、1.、1)、- 或 + 且紧跟中日韩字符时，补回空格再读。按块处理，所以不会碰到代码（cjk-blocks.ts）
公式由词法分析得到，渲染成保存原文的 .md-math；KaTeX 只画这些，从不扫描正文。和 Pandoc 一样：$ 后面必须是非空白，结尾的 $ 前面是非空白、后面不是数字。\(…\)、\[…\]、$$…$$ 总是公式（math.ts）

保持原样

写法原因
#话题#今天话题标签：一个 # 由另一个闭合
1.5倍点后面是数字
1、、（1）、•纯文字本来就像编号
行首的 *强调*是强调，不是列表
用 ｜ 的表格少见，而全角竖线也是普通文字
带空格的网址空格就是结束，各处一样

用户自己的消息和 A2UI 文字使用同一组扩展，但不含公式：人输入的内容保持原样。
