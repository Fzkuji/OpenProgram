macOS App 图标规范

面向 desktop 打包与品牌资源维护。现代 macOS 使用 Apple Icon Composer 分层资源；OpenProgram 提供深蓝背景与四个独立品牌深度层。素材不预画最外层系统轮廓，圆环和三个节点使用高饱和蓝紫色与凸起受光。

最终决策

1 · 背景定义

背景颜色由 icon.json 的 automatic-gradient 定义。素材本身不含圆角。

+
2 · 四个透明品牌层

轨道与三个节点分别使用独立 SVG。三个节点位于前景，包含深色内场的轨道层位于其后。

→
3 · 系统输出示意

最外层圆角遮罩及其边缘效果由 Apple 工具链生成；内部节点的受光方向属于品牌素材，Icon Composer 只为这些节点添加层间阴影，不添加 Specular 光圈。

素材边界

源素材保留1024 × 1024 画布、深蓝背景基色、带方向性受光的高饱和蓝紫轨道、三个带凸起受光渐变的独立节点、透明前景、安全边距和清晰轮廓。
源素材禁止外部 squircle、圆角矩形、外框、最外层轮廓高光、预画投影、模糊、系统容器材质和预合成背景。
Apple 工具链负责最终遮罩、组间深度、系统高光、折射、透明度、投影、平台外形、显示模式适配以及兼容资源生成。
组件资源不得替代Web favicon、侧边栏图标和加载动画继续使用各自尺寸的现有资源，不从 App 图标截图导出。

依据与验收

设计依据为 Apple 的 App icons HIG、Icon Composer 与 Xcode 图标创建说明。打包能力依据 Electron Builder 图标文档。

聚焦校验必须确认：四个现代 SVG 均使用 1024 × 1024 透明画布且不含外部 squircle、外框或最外层高光；三个节点使用左上受光的径向渐变；圆环同时包含深色内场、方向性蓝紫渐变和不含白色的暗边截面渐变；icon.json 将三个节点置于前景、轨道置于后景，四组均关闭 Specular，并使用 42% neutral Shadow；发布 runner 提供 Xcode 26。ictool 必须成功导出 1024 × 1024 Default 预览，最终视觉验收检查 Dock、Finder、About 面板和相邻官方图标下的尺寸与层次。
