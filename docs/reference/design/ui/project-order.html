Sidebar projects and conversations

Complete sidebar contract

The reference screenshots specify pin/unpin, editing the display name and icon, custom sections, revealing folders, creating a persistent worktree, archiving project chats, and removing a project. The edit dialog supports source folders. OpenProgram also provides opening project settings and starting a new project conversation. Removing a project removes its registration only, never its files or conversation content.

Project ordering is independent from conversation ordering. Recent activity sorts by the newest timestamp of any conversation in the project; oldest activity and alphabetical ordering are also available. Pinned projects stay above unpinned projects. Dragging selects manual order and retains all hidden projects. Conversation sorting has explicit ascending and descending directions. Preferences survive reload and synchronize between windows.

Current behavior and choices

The registry owns membership. The existing projectGroups join sorts default-first and then by name. Manual ordering applies after that join, preserving membership and session sorting. The user-provided Codex screenshot supplies the interaction reference: draggable project rows and an insertion line. Pointer capture, a six-pixel movement threshold, and explicit release/cancel handling require no dependency; transferring sessions or projects between sections is excluded.

State and boundaries

A project ID array in the existing recents view preference stores the order locally. Unknown IDs are ignored; new projects follow the existing fallback sort. Hidden projects retain their order when another project moves. Storage events synchronize windows. Invalid persisted arrays fall back to the default order. Storage failures keep the visible order for the current window and announce that persistence failed.

Acceptance

Through the Projects sidebar, dragging upward or downward changes order only on drop. Escape or a drop outside the list leaves order unchanged. Reload retains order. Collapse, new-session buttons, membership and filters retain their behavior. Keyboard moves keep focus and announce the result.
