ConvItem 决定状态，StatusMarker 绘制。选中用 aria-current="true" 表示。CSS 在未选中行屏蔽运行和结束的伪元素。

什么算运行中

对话里只要有一轮占着运行槽，这一行就是运行中，不管在哪条分支：选中分支的轮次（runningTasks），或别的分支上的轮次（sessionsWithBranchRun，数据在 lib/chat/run/other-branch-runs.ts）。输入框的停止键仍只管选中分支（轮次占用）。

轮次这一行
输入的消息、重试、编辑从准入到结束都是运行中
Goal 的下一轮、它的验证、从控件启动的 Goal整轮都是运行中，在 Goal 跟随的那条分支上；两轮之间没有东西在跑，这一行是空闲
后台命令结束的通知智能体回应它的时候是运行中
未选中分支上的轮次运行中；在那里等人回答或已失败的轮次不算
帮手智能体、Job、常驻签到不算这一行的状态，它们显示在活动面板里
  • 为什么算任何分支：这一行代表对话，不代表某个窗格显示的分支。人选了别的分支以后 Goal 还在自己的分支上干活，这时一行空闲等于说什么都没在跑。
  • 中途连上的客户端每次连接问一次 get_running_sessions 并应用回答（lib/chat/run/running-sessions.ts）；它还显示为运行中、回答里却没有的行，用 get_run_state 再问一次并清掉。
  • 存下来的 status：一轮结束时还有另一轮在跑，对话的状态保持 running（mark_session_finished）；这一行的运行标记不读它。
  • 测试：apps/web/tests/chat/run/running-sessions.test.mjs、tests/component/runtime/test_owner_turn_run_slot.py。
