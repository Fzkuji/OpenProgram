Discussion behavior

Chat about this rejects the displayed request through the canonical wait command. After its applied acknowledgement, it automatically queues a short user message explaining that the request is rejected and discussion is needed. The ordinary chat sender starts a text-only model reply when the previous execution is idle. The user can then send a separate follow-up. The composer draft is unchanged: no request JSON, quote card or prefilled message is inserted.

The shared send queue preserves session ownership, ordering and reconnect behavior. Duplicate clicks share one command and one notification; a failed or unconfirmed decline displays an error and does not send a misleading rejection message. Deny and approval scope behavior remain unchanged. The only automatic model turn disables tools and web search; later user turns retain their configured settings.
