交互与状态边界

独立控制收起 Settings 或 Provider 不修改另一列状态。 用户状态优先改变窗口宽度不自动展开或收起导航列。 持久化刷新和重新进入 Settings 后恢复用户最后一次选择。 键盘与读屏按钮保留原生 button、aria-expanded、aria-controls 与明确名称。 内容适配窄窗口只触发表单控件换行；详情数据、选择和滚动状态不变。 层级表达Settings 名称属于二级导航栏头；Provider 第三级不增加独立名称栏头。

采用与排除

采用

  • 复用现有两态收起状态和图标。
  • 删除全局 Settings 顶栏。
  • Memory 不增加重复页头，Providers 恢复完整页面标题栏。
  • 只在 Settings 二级栏头显示名称和按钮。

排除

  • 不增加拖拽调整列宽。
  • 不按 breakpoint 强制改变用户状态。
  • 不修改 Memory、Provider 或模型数据。
  • 不改变应用主侧栏行为。

验收标准

  • Settings 页面不再渲染独立的全局 Settings 顶栏。
  • Settings 分类栏展开时显示 Settings，按钮与名称同一行；按钮顶边与主侧栏按钮一致。
  • LLM Providers 列表栏不显示新增名称栏头，折叠按钮恢复到搜索框旁；原有状态和 49px 收起行为不变。
  • LLM Providers 在列表和详情上方显示页面大标题与介绍，路由 loading 状态保持同一结构。
  • Memory 内容区继续不显示重复标题和介绍。
  • 现有两处 localStorage key、键盘语义、图标选择和 49px 收起宽度保持兼容。
