左侧栏宽度与收起状态

左侧栏支持手动调整宽度，但手动宽度不能覆盖收起状态，也不能把中央内容压缩到不可用。

状态约束

状态宽度规则行为
展开180–480px；窗口较小时至少为中央内容保留 360px拖拽实时调整；超出上限时停止增长
收起固定 49px收起态覆盖拖拽产生的内联宽度
重新展开恢复收起前的合法宽度不因收起而丢弃用户刚调整的宽度

实现边界

拖拽继续使用现有 useColResize。状态约束在左侧栏的共享 CSS 入口实现，不修改右侧栏、分屏比例或内容页布局。

验收

将左侧栏拖到最大宽度后点击收起按钮，应立即回到 49px；再次展开恢复之前宽度。任何窗口宽度下，中央区域不应因左侧栏继续增长而低于 360px，除非整个窗口本身小于 540px。

实现状态

已实现：收起态强制宽度、展开态最大宽度、重新展开恢复宽度，并加入针对 CSS 优先级和上限的回归检查。
