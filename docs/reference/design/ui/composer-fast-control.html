Behavior contract

  • Replace the question-mark button at the top right of the existing thinking panel with a GaugeIcon button. Keep the effort heading and slider in place. Use the user-supplied GaugeIcon paths and spring animation (stiffness 160, damping 17, mass 1) in the React implementation. The idle needle means off; the advanced needle remains visible while Fast is on. The icon stays unfilled. Activation adds no border or background. A focus ring appears only for keyboard focus, independently of the selected state. Hover animates the needle; keyboard focus exposes the state and provider-specific usage note. Remove the duplicate Fast menu item; do not add a separate speed pill. When the panel is closed, a small gauge glyph inside the existing effort pill indicates Fast is on. No fixed speed multiplier is copied from the reference screenshot.
  • Default is Standard. Save the selection per session and route/model identity. An unseen route starts at Standard; changing models must not silently enable a paid tier. Restore existing session preferences only for the original supported route.
  • An unverified route keeps a visible, focusable, unavailable control with an explanation. It must not be described as a model that categorically lacks Fast. Explicitly unsupported and unknown are distinct capability states.
  • Changing speed applies to the next submitted turn. Queued messages retain their submitted setting; a running request is unchanged. Fast does not change Xhigh or another thinking setting.
  • Standard explicitly overrides an agent’s priority default. Do not represent “off” merely by omitting the field, because the current loop can then inherit that default.
