斜杠命令与上下文压缩

斜杠命令

输入以 / 开头且没有空格时，菜单从 / 处向上弹出，和 @ 菜单是同一种玻璃浮层，每条命令一行，带图标、参数和说明；内置命令各有图标，技能、插件和用户命令用各自来源的默认图标；出现空格立即收起。

Enter 执行已注册的首词，否则发送聊天。正在关闭的菜单不拦截 Enter。技能、插件和用户命令来自 /api/commands；内置命令派发优先。

命令选择或 Enter
/compact [keep_recent_tokens]立即压缩
/rewindWeb：打开选择器选一条较早的消息，不带参数。默认 TUI 没有这个命令。仅 Rich 回退界面：列出回退点；/rewind N 预览；/rewind N confirm <plan_hash> <idempotency_key>（预览时打印）回退
/branch [name]立即执行
/context打开圆环面板
/clear、/new新对话
/task、/skill、/merge填入前缀，等待必填参数
/help把输入设为 /，重新显示菜单；没有单独页面
/sandbox开关系统沙箱
/memory打开记忆页
/doctor运行健康检查，在本地显示报告，不发给模型

可选参数（只有 […]）立即执行。没有会话时，会话命令保留输入并提示“先开始一段对话再执行此命令”。

由服务端执行的命令（/api/commands 里 type: "local" 的：/goal、/rename …）作为输入框自己的消息发出，走 sendChatMessage：

  • 从“新对话”草稿发出时带上草稿的 local_* id、权限模式、Agent、项目和目录：在草稿里执行，标签页就成为这段对话。
  • 它自己不画气泡。接着开始一轮的命令（/goal <目标>）在 chat_ack 时得到它的消息，回复开始之前就出现；只回答的命令（/goal status、/goal pause）只留下回复行。
  • 运行中或有请求等待时立即发出，跟当前这轮并行，不出气泡。
已知小问题
  • 注册表里也叫 compact 的项目会在菜单里重复；派发仍选内置。
  • “跳到最新”可能与菜单位置重叠。

压缩后发送什么

只有一份滚动摘要。再次压缩把旧摘要和更多轮次合成新摘要。

[System prompt] [Current summary] [Recent uncompacted turns] [New user message]

触发

触发条件路径
手动 /compact从输入框执行，可选保留最近 N token。是选中分支的前台操作（op_kind: compact）：每个客户端都在运行指示处显示“正在压缩上下文…”和停止按钮，刷新后也一样；停止发带 op_id 的 operation.cancel。该分支忙时被拒绝，并写明正在运行的是什么；其他分支照常运行。结束帧在槽释放后才发出，释放时发 running_task_clear。终端界面显示进度和结果。action: compact、handle_compact
自动，轮次开始前预算达到 context.auto_compact_percent（默认 80）。压缩这一轮所在的链，任何分支都一样；head 不动。后台轮次跳过。loop_runner.py
自动，轮次之中一轮工具结果越过同一阈值：每轮一次（mid_turn），然后继续这一轮。分支换到窗口更小的模型时，下一轮开始前由窗口更大的模型压缩（model_downshift）loop_runner.py
溢出恢复模型返回 413 或 prompt_too_long：在 agent 循环里压缩，再发同一个请求；每个请求一次、每轮两次，这一轮不会从头重跑reactive.py

它们都用 compaction_started、compaction_finished、compaction_failed。开始显示在运行指示处。/compact 结束时加一条系统消息，被停止的显示“已停止压缩，上下文保持不变”。回合自己的压缩失败时不显示：历史没有变，之后的请求会再试。

步骤

  1. 读取 SessionDB 渲染后的历史：摘要和剩余轮次。已被覆盖的原文不重读。
  2. 阈值。少于四条消息：停止，手动路径会说明。已经是摘要加尾部且没有有效切点：无可压缩，不调用模型。
  3. 摘要，单独一次模型调用。默认尾部：窗口的 10%，限制在 8k–40k token，至少四条非空消息。/compact 2000 可覆盖。
  4. 持久化 summary_* 节点（role=llm、name=context/summary，以注明自己是摘要的用户消息发送）；covers_ids 标记范围。旧轮次保留，HEAD 不动。
  5. 图。DAG 显示胶囊。一条链只有一个生效的摘要，即覆盖最远的那个；更早的被取代，不再参与渲染（压缩）。

圆环

右下角：占用除以窗口大小，基于压缩后的视图。低于 50% 绿色，50–80% 黄色，80% 及以上红色。测量、运行状态、无可压缩和“立即压缩”见占用与压缩。
