手机布局

宽度在 760px 及以下时，外壳是单列的手机 App。断点只有一个常量 PHONE_MAX_WIDTH，和二级侧栏原来用的是同一个。其余都是最后加载的 styles/base/phone.css，加上 phone-shell.tsx 里的手势。760px 以上什么都不变。

  1. 对话标签行、单列、输入框
  2. 标题按钮或从左边缘滑入侧边栏盖到页面上
  3. 点一个对话、点遮罩或滑回去抽屉关上，停在选中的对话

各个界面

部分手机上
侧边栏抽屉，宽 min(86vw, 320px)，下面盖一层 --scrim。用标签行或页面标题最前面的按钮、或从左边 24px 内滑动打开；用它自己的收起按钮、点遮罩、向左滑、或选中对话、页面、标签关上。拖动时跟手，松手按距离或甩动速度决定开关。它一直挂着，再打开时停在原来的滚动位置。关上后不留图标栏。
对话中间卡片占满屏幕；消息左右留 12px，输入框与之对齐。消息刻度条住在侧边留白里，手机上不显示；视图控件保持窄的竖条，离右上角 8px。代码块和表格在自身内部横向滚动。
右侧面板从右边滑进来的整屏面板，用标签行最后的按钮打开，用它的收起按钮或选中标签关上。工具详情、文件、活动和资源都占满宽度。
设置、历史、项目、智能体二级侧栏就是本页的分区列表，占满宽度；点一行打开内容。列表页标题前只有侧边栏按钮，内容页只有回到列表的返回箭头。
管理页抽屉按钮、侧栏按钮和标题在标题栏第一行；标签和工具栏换到下面。原来给收起图标栏留的 62px 去掉。
输入框和提问卡片三段式输入框布局不变，占满这一列；提问和审批卡片在输入框里，所以也是满宽。

触摸和屏幕边缘

规则做法
键盘外壳 position: fixed，顶部和高度跟随可视视口（visualViewport 写入的 --phone-viewport-top、--phone-viewport-h），没有时用 100dvh，所以在 Safari 里输入框也停在屏幕键盘之上。
刘海和底部横条外壳按 env(safe-area-inset-*) 留边；抽屉和整屏面板至少留 8px 或安全区。
触摸目标标题按钮、抽屉和面板里的行、分区列表的行都是 44px。
输入框字号至少 16px，聚焦时页面不放大。
悬停手指点按不会打开悬停提示；消息操作本来就不需要悬停就可见。
保存的选择在手机上开抽屉、面板或分区页都不保存；保存为打开的右侧面板在手机上启动时是关的。宽窗口保留自己的选择。
动效抽屉和面板滑动 220ms；拖动跟手；减少动态效果时不滑动。

从 dsh-mobile 照搬的部分

设计照搬 saya-ch/dsh-mobile（Apache-2.0），它是另一个框架网页界面的触摸布局，没有自己另想一套。

决定原因
会话列表做成带遮罩的覆盖抽屉对话占满宽度；列表一滑就到，并保留滚动位置。
右侧面板做成整屏手机上 300px 的一列放不下正文；整屏能满宽看详情。
设置分区做成可返回的列表页分区列表和内容挤不进 390px。
高度跟随键盘、安全区留边、44px 目标、16px 输入框它的设计系统清单：主操作在键盘之上，刘海下不放东西，聚焦不放大。
页面不横向滚动，宽内容在自身内部滚动同上。

没有照搬：它在对话旁边保留的 56px 折叠图标栏（OpenProgram 在手机上不留图标栏），以及平板停靠区间（761px 起本来就是桌面布局）。

实现状态

页面 viewport 声明了 viewport-fit=cover。interactive-widget=resizes-content 还没有声明；没有它，可视视口高度也能处理键盘。
