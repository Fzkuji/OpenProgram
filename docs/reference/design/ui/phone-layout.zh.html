手机布局

宽度在 760px 及以下时，外壳是单列的手机 App。断点只有一个常量 PHONE_MAX_WIDTH，和二级侧栏原来用的是同一个。其余都是最后加载的 styles/base/phone.css，加上 phone-shell.tsx 里的手势。760px 以上什么都不变。

  1. 对话标签行、单列、输入框
  2. 标题按钮或从左边缘滑入侧边栏盖到页面上
  3. 点一个对话、点遮罩或滑回去抽屉关上，停在选中的对话

各个界面

部分手机上
侧边栏抽屉，宽 min(86vw, 320px)，下面盖一层 --scrim。用标签行或页面标题最前面的按钮、或从左边 24px 内滑动打开；用它自己的收起按钮、点遮罩、向左滑、或选中对话、页面、标签关上。拖动时跟手，松手按距离或甩动速度决定开关。它一直挂着，再打开时停在原来的滚动位置。关上后不留图标栏。
对话中间卡片占满屏幕；消息左右留 12px，输入框与之对齐。消息刻度条住在侧边留白里，手机上不显示；浮动的视图控件也不显示，它们的操作在标题菜单里。代码块和表格在自身内部横向滚动。
导航栏标签行变成 48px 的导航栏，只有两个按钮，和 Claude、ChatGPT 的手机 App 一样：左边两道横线打开左侧抽屉，右边的写字图标开新对话。中间是当前页面的标题；在对话上标题带一个小箭头，点开是这个对话的菜单。标签、前进后退、窗口总览和主菜单不显示。
对话菜单文件、活动、资源打开右侧抽屉的对应视图；上下文图切换视角；然后是对话区自己的会话操作（components/chat/pane/session-actions-menu.tsx）：显示方式、重命名、自动命名、置顶、复制链接、复制会话、归档、删除。“设为默认显示方式”只留在电脑上。
菜单手机上所有菜单的行高 40px、字号 16px，不显示快捷键字母和数字。触屏手机上所有菜单、弹出框和思考档位卡片都是底部面板（components/ui/menu/phone-sheet.tsx）：离屏幕边缘 8px，圆角与屏幕圆角平行，顶上有拖动条，背后的页面变暗。子菜单在父菜单上方打开成新面板，第一行是“返回”。往下滑或点面板外面关闭。模型菜单把每个提供方的状态放在名字下面。
一次一个页面在触屏手机上（App、手机浏览器），打开一个页面就关掉前一个，标签不会在看不见的地方越堆越多；写字图标直接在原地开新对话，不打开新标签页。窄的桌面窗口保留它的标签。
右侧面板和左侧抽屉对称：从右边缘出来，min(86vw, 340px) 宽，盖在同一层遮罩上。从对话菜单或从右边 24px 内滑出来打开；用它的收起按钮、遮罩、往右滑或选中标签关上。拖动和左侧抽屉一样跟手。
消息用户的消息是主题强调色填充、白字的气泡，靠发送方的角更小；助手的回复仍是正文。
设置、历史、项目、智能体二级侧栏就是本页的分区列表，占满宽度；点一行打开内容。列表页标题前只有侧边栏按钮，内容页只有回到列表的返回箭头。
管理页抽屉按钮、侧栏按钮和标题在标题栏第一行；标签和工具栏换到下面。原来给收起图标栏留的 62px 去掉。
输入框和提问卡片三段式输入框布局不变，占满这一列；提问和审批卡片在输入框里，所以也是满宽。触屏手机上，回复进行中时提示写“补充到这一轮”，不写键盘快捷键。

触摸和屏幕边缘

规则做法
键盘外壳 position: fixed，顶部和高度跟随可视视口（visualViewport 写入的 --phone-viewport-top、--phone-viewport-h），没有时用 100dvh，所以在 Safari 里输入框也停在屏幕键盘之上。键盘弹出时外壳去掉底部安全区留边，输入框贴着键盘；手机 App 还去掉了网页表单在键盘上方加的“上一项、下一项、完成”那一栏。
圆角浮在页面上的东西和屏幕边缘保持均匀的间距，抽屉 8px、弹窗 16px，圆角取屏幕圆角减去这个间距，和屏幕的圆角平行。手机 App 把屏幕的真实圆角写进 --phone-screen-radius；浏览器在有底部横条的屏幕上按 55px 算，否则按 24px。抽屉伸到状态栏和底部横条下面，内容避开这两处。
刘海和底部横条外壳按 env(safe-area-inset-*) 留边；抽屉的内容留在安全区里（见上面的圆角）。
触摸目标标题按钮、抽屉里的行、分区列表的行都是 44px。触屏手机上，输入框的两排小按钮（电脑、频道、文件夹；工具、思考档位、模型）和菜单里的图标放大到 1.2 倍，图标看得清，按钮是 34px。
输入框字号至少 16px，聚焦时页面不放大。
悬停没有悬停能力的设备上不打开悬停提示，点按时系统合成的鼠标事件也不会；消息操作本来就不需要悬停就可见。
保存的选择在手机上开两边的抽屉或分区页都不保存；保存为打开的右侧面板在手机上启动时是关的。宽窗口保留自己的选择。
动效两边的抽屉滑动 220ms；拖动跟手，松手后从手指离开的位置接着滑；减少动态效果时不滑动。

从 dsh-mobile 照搬的部分

设计照搬 saya-ch/dsh-mobile（Apache-2.0），它是另一个框架网页界面的触摸布局，没有自己另想一套。

决定原因
会话列表做成带遮罩的覆盖抽屉对话占满宽度；列表一滑就到，并保留滚动位置。
右侧面板做成右边缘的抽屉dsh-mobile 用的是整屏面板；手机聊天 App 用和左边同样的滑动从右边缘拉出侧栏，对话还露在边上。
设置分区做成可返回的列表页分区列表和内容挤不进 390px。
高度跟随键盘、安全区留边、44px 目标、16px 输入框它的设计系统清单：主操作在键盘之上，刘海下不放东西，聚焦不放大。
页面不横向滚动，宽内容在自身内部滚动同上。

没有照搬：它在对话旁边保留的 56px 折叠图标栏（OpenProgram 在手机上不留图标栏），以及平板停靠区间（761px 起本来就是桌面布局）。

实现状态

页面 viewport 声明了 viewport-fit=cover。interactive-widget=resizes-content 还没有声明；没有它，可视视口高度也能处理键盘。
