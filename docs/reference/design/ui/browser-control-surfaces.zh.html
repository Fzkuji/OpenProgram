这些按钮做什么

我来操作 是请 Agent 停止在这个网页上点击和输入。它不是重新加载页面，也不是浏览器对正在加载文档的停止。程序确认暂停之前，不要写成「已暂停」。确认之后由你点击和输入，Agent 不再操作。

让 Agent 继续 是你明确允许 Agent 再次点击和输入。超时、重连或打开恢复的标签都不会替你做这件事。普通暂停在确认之后用这几个字。

需要你确认 不是普通暂停。Agent 正在等所属对话里已有卡片上的允许或拒绝。网页上的半透明按钮必须和「已暂停」看起来不一样。点它会打开那次对话，并把已有的允许 / 拒绝卡片滚进视野。它不会替你批准。它不是「让 Agent 继续」。不要在网页或浏览器顶栏再画一张允许 / 拒绝卡片。

显示操作 / 点击标记 在 Agent 最近点击或输入的位置画短时标记。它们不改变网页收到的输入。

操作历史 列出这个网页上最近的 Agent 步骤。它是日志，不能撤销那些步骤。

半透明按钮仍挡住底下的内容。按钮周围的空白不影响点击网页。要点击被挡住的内容，把可拖动的小按钮挪到别处，或把操作收起。
