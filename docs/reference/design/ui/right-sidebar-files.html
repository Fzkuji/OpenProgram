文件树与基础文件管理

文件树不再为每个目录增加独立折叠箭头。目录图标本身负责展开与收起；展开后的竖线从父目录图标中心向下延伸，子项通过短横线接入，形成命令行文件树的父子结构。项目工具栏继续保持既有对齐。在此基础上补充排序、显示选项和详细信息，并统一侧边栏与中央 Files 的基础操作。本页是这一主题的设计依据，不依赖旧 workspace 原型。

采用与排除

  • 采用：项目工具栏继续复用顶部导航的水平内容结构；项目名保持较小、较粗的上下文标签样式。
  • 采用：文件树使用图标与名称两列；根级图标和名称分别与项目工具栏的图标和项目名对齐。
  • 采用：每一级子项图标从父级名称起点开始，形成一致的逐级嵌套关系。
  • 采用：目录关闭时显示普通文件夹，展开时显示打开文件夹；整行继续作为展开点击区。
  • 采用：层级线只出现在已经展开的父子关系中，最后一个子项的竖线停在该行中点；选中、活动和 hover 背景不得遮断层级线。
  • 采用：项目行继续使用底部分隔线，不增加卡片背景、阴影或第二个选中面。
  • 不采用：为项目名增加展开箭头。当前项目根不可折叠，箭头会表达不存在的操作。
  • 不采用：把操作按钮平均分布。它们是一个右对齐的操作组，平均分布会削弱项目名与操作的关系。
  • 不采用：保留独立箭头、圆点或额外展开按钮；它们会重复表达目录状态。
  • 不采用：让父级名称与子级图标左右错开；层级步长由图标槽和名称间距共同决定。

顶部路径导航

Symbols 文件夹图标仅用于文件管理器内部的目录行、搜索结果和新建行，支持打开与关闭状态。Files 入口、项目导航、工作目录、文件选择、Programs 和书签保留原有图标。排序菜单只显示可操作选项，不放置实现说明。

路径与工具栏使用共享 HoverTip 圆角提示，不叠加浏览器原生 title 提示。父级菜单和排序选项复用现有圆角菜单样式，悬停与键盘焦点可辨识；排序使用带选中标记的菜单项，不使用原生方形下拉选项。

刷新重新读取目录和大小，同时保留当前选中路径、已展开目录和已加载的分页范围；请求期间保留现有目录行，只有切换项目才重置路径。普通文件行大小、14px 路径、右侧绝对路径复制和刷新状态保留已通过组件测试与默认 App 验收。分页刷新期间保持旧行；失败显示重试入口，重试成功后恢复继续加载。

顶部显示从项目根到当前目录或文件的分段路径，使用低对比度分隔箭头；父级使用次要文字，当前项使用主文字，不再只显示一个文件夹名字。例：OpenProgram → docs → reference → design → ui → right-sidebar-files.html。

  • 侧边栏路径反映当前选中的文件或目录；点击父级在原文件树中展开并定位该目录，不替换项目根或将树改为平铺列表。文件标签的路径反映当前打开文件。
  • 路径独占完整宽度的一行，文字为 14px；最右侧使用原有 28px 图标按钮复制当前完整绝对路径，路径折叠只使用扣除复制按钮后的可用宽度。原有操作与新增排序、详情按钮集中在第二行，保持原有按钮相对顺序与尺寸。搜索展开区继续位于操作行下方，左右各 8px，不与路径争用宽度。
  • 根据路径行实际宽度和文字宽度，尽量显示更多靠近当前项的父级；剩余宽度不足以显示完整父级名称时，允许最前面的可见父级截断显示，优先保留当前项完整；仅在连可辨识的父级片段也放不下时继续折叠。只有确实放不下的前部层级收进“…”菜单，始终保留项目根和当前项，不按固定侧栏宽度提前折叠。当前项仍过长时截断并提供完整名称提示；菜单列出被折叠的父级，可用键盘选择。详情中保留完整绝对路径与复制入口。
  • 路径没有选中对象时显示项目根。重命名或移动后同步更新；目标消失时退回最近仍可访问的父级。选中和定位不会授权浏览项目之外的路径。

排序与显示规则

顶部采用三行结构：第一行为完整宽度的路径导航；第二行为操作按钮，依次为搜索、新建文件、新建文件夹、刷新、排序与显示、详细信息；第三行仅在搜索展开时显示搜索框及选项。原有按钮的 SVG、28px 点击区与 4px 间距保持不变，新增按钮采用相同样式。详细信息同时保留文件右键入口。

选项明确行为
名称默认升序，自然数字顺序、忽略大小写；同名排序值用原始名称确定稳定顺序，如 file2 排在 file10 前。
修改时间／大小／类型时间和大小首次选择默认降序，类型默认升序。类型按规范化扩展名分组，无扩展名归“其他”；相同值按名称升序。缺失元数据始终排在同组末尾。
文件夹优先默认开启，升降序不反转目录与文件分组。未统计的目录大小显示“—”，已有结果区分完整、部分和待更新。不以目录项自身字节数代表递归大小；文件夹同样提供大小：优先显示缓存估值并后台核实，完整统计后可在目录分组内按大小排序；部分统计与未知项单独置后，不当作完整总量比较。
显示隐藏文件与 Git 忽略项分开控制；默认值沿用现有产品规则，避免升级后意外隐藏项目内容。被禁止访问的路径不因显示开关而可见。
作用域与保存只重排各目录内的直接子项，保留展开集合、当前文件和可见选中项。排序与显示偏好按本地实例和项目保存，在侧边栏与中央 Files 同步；不写入项目配置，不跨设备同步。
搜索沿用 Filter / Highlight / Fuzzy。目录排序不更改搜索相关度语义；搜索结果明确显示“相关度”，回到目录后恢复目录排序。

文件夹大小

文件夹行也显示大小，不长期只显示“—”。有缓存先显示“约 12.4 MB”，后台核实；首次扫描尚未完成显示“至少 14.8 MB”，完成后显示“18.6 MB”。这些数字仅为交互示例。没有可靠缓存时不编造总量估计，不能把部分累计字节显示成最终大小。

可见目录按需排队，限制并发与扫描预算；不扫描未展开树中的所有后代目录。统计可取消或继续；权限不足、内容变化和超出预算分别标记。选中项详情展示缓存时间、统计状态及重算入口；目录大小属于第一阶段需求。

详细信息与空间分配

文件或目录右键菜单增加“详细信息”。侧边栏使用可关闭的详情浮层，中央 Files 使用右侧信息区，复用相同内容；窄窗口改为对话框。打开时焦点进入面板，Escape 关闭并回到触发项。普通单击文件仍打开现有编辑／预览标签，不改成仅选中。

信息展示与边界
基本信息文件名、类型、完整路径、相对路径；路径可复制。普通文件行右侧显示可读大小（含 0 B），悬停显示准确字节数；详情同时显示两者。
时间与权限修改时间、创建时间使用本地时间，明确时区；不支持的创建时间显示“不可用”，不能使用 ctime 代替创建时间。权限只读展示，不在第一阶段增加 chmod 操作。
符号链接识别链接本身；仅在项目访问策略允许时显示目标。失效链接明确标记，不自动跟随到项目之外。
目录统计当前可见目录按需排队统计，有缓存先显示“约 X · 待核实”，无缓存显示“正在统计”；打开详情提高该目录统计优先级。估值来自上一轮统计缓存，不从文件数量猜测总大小；有数量和时间上限，可取消。未完成时显示“已统计至少 X · 尚未完成”，允许继续，不把累计值冒充预估总量。结果缓存，变化后标记待更新；不同时扫描文件树中的所有目录。权限不足或超过上限明确标注部分结果。
加载与错误独立加载状态；文件已删除、无权限、查询失败分别显示并支持重试。快速切换文件时取消旧请求或忽略旧响应，不能把上一个文件的信息展示给新选中项。

基础操作组织

现有的新建、剪切、复制、粘贴、重命名、删除和路径复制继续使用原文件操作接口。共享菜单按对象类型调整：文件可打开和下载，目录可新建子项；粘贴目标必须明确显示为目录。右键目标不隐式打开文件或改变目录展开状态。

分组操作与反馈
打开与查看打开、在中央 Files 中定位、在系统文件管理器中显示、详细信息。远程实例不提供客户端 Finder 定位服务端路径的假操作。
创建与组织新建文件／文件夹、剪切／复制／粘贴、重命名；后续补充移动到／复制到的目标目录选择器。重命名默认选中主体，保留扩展名。
同名冲突展示源和目标，选择保留两份、替换或取消。第一阶段不支持目录合并；未明确选择前不覆盖。剪切仅在移动确认成功后清除剪贴板。
删除先核实后端是否具备恢复能力。能够恢复才显示“移到废纸篓”；否则明确显示永久删除及目标范围，不把操作日志等同于可恢复副本。新增回收与撤销机制另列实施项。
未保存编辑移动、重命名与删除必须复用既有草稿保护和标签同步。取消操作不丢草稿；失败时保留输入与选中项，反馈实际结果，不只显示乐观成功。

实现边界与分阶段验收

目录接口保留 dirs_first_path 兼容调用。管理排序由服务端在分页前执行，并进入 snapshot 与 cursor 身份；排序、显示条件或项目变化后丢弃旧 cursor。客户端不能只排序已加载的一页。详情使用独立元数据查询，不为查看属性而读取整个文件。读查询不改变现有文件修改权限。

阶段交付范围验收
一 · 排序与属性排序与显示菜单、元数据详情、文件夹大小估值与后台统计、两处 Files 偏好同步、右键入口。超过一页的目录顺序正确且无重复遗漏；切换条件不混入旧结果；240px 下六个 28px 按钮及五个 4px 间距共 188px，能在 224px 内宽中完整显示；鼠标与键盘可操作；错误信息与当前目标一致。
二 · 管理操作完善统一菜单、目标目录选择、同名冲突、草稿和打开标签同步。取消不修改磁盘；权限与并发失败可重试；跨目录移动成功后源与目标及时更新；恢复能力未实现时不承诺撤销。
后续独立范围中央详细列表列视图、多选批量操作、拖拽移动、可恢复删除。不作为第一阶段前置要求，不用中央详细列表替换现有侧边栏目录树。

复用 共享文件类型图标；查询、草稿与恢复语义继续遵循 文件操作设计。本页只定义文件浏览与管理入口，不重复维护历史恢复合同。
