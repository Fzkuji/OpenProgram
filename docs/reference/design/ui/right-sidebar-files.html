边界与功能接入

能力当前设计
显示与交互Pierre 负责行布局、层级、选中、焦点、虚拟滚动、键盘导航。目录使用 icons.remap 与自定义 sprite；展开状态切换开合路径，禁止旋转文件夹。
路径与工具栏文件树与导航、工具栏统一使用 8px 左右外留白。第一行 14px 自适应面包屑，路径按钮至少 32px 高、水平内边距保持 8px，箭头两侧不加 gap，不显示重复名称的悬浮提示，右端复制完整绝对路径；第二行搜索、新建文件、新建目录、刷新、排序、信息；第三行按需展开搜索。保留现有按钮与圆角菜单。
查询与排序project_file_tree 仍按目录懒加载、分页及排序。框架比较器保持后端顺序，支持名称、类型、修改时间、大小与文件夹优先；不擅自回到字母排序。
文件与文件夹大小普通文件显示字节数；可见目录复用有界后台统计，搜索忽略目录（如 .cache、node_modules）仍可查看元数据与计算大小，保留缓存、扫描中、完整、部分、取消、错误状态。列表直接显示大小数值，不附加 ≈ 或 ≥；正在统计且已有数值时，仅该数值以灰色缓慢明暗变化，数值继续更新；统计停止后恢复正常，不新增文字或图标；暂无数值时留空，不显示占位横线；估算、统计下界及完成状态保留在详细信息中，详细信息可继续计算。
搜索与定位搜索仍使用后端权限范围与分页。结果使用 Pierre 层级显示；高亮模式保留目录。模糊匹配继续由后端判定，以匹配标记及当前项原生选中状态表示；字面查询使用框架文本高亮。定位通过控制器展开与滚动，不依赖旧手写行 DOM。
新建、重命名与右键现有新建与重命名表单验证后再提交；不允许框架内部移动替代服务端操作。右键继续提供详情、系统定位、创建、复制路径、剪切、复制、粘贴、重命名及删除确认。
刷新与错误保留选中路径、展开目录和已加载分页；等待刷新时保留旧行。父目录收起后保持关闭，即使内部子目录曾展开；重新展开时恢复子目录状态。滚动接近已加载目录末尾时自动读取下一页，不设置固定分页按钮；失败时停止自动重试并提供显式重试。蓝色选中行不显示边框；未选中行的键盘焦点指示保留。文件管理工具栏与列表之间不显示分隔线；文件树取消上下额外内边距，横向外边距缩至 4px。目录加载与分页失败给出路径及重试入口，不显示虚假的文件条目。
状态与权限工作区范围、请求取消、过期响应隔离、草稿保护和服务端幂等变更保持现有合同。框架不接触真实文件内容和权限判定。

参考与选择

采用 Pierre Trees 官方 React 接口，固定版本 1.0.0-beta.6。已核对本机 Codex 的文件树实现及同源 SVG。保留 Lucide 文件夹与产品导航图标；不继续维护手写递归行、固定 27px 缩进和自定义横向连线。不启用会绕过服务端验证的客户端拖放移动。

共享文件类型图标见 图标设计；文件内容、草稿与恢复合同见 文件操作设计。Apache 2.0 与图标 MIT 许可随产品发布。

实现状态

已接入官方组件。394 项 Web 测试、511 项合同测试、Web 检查、类型检查、生产构建和独立复核通过。默认 App 深色界面已核验目录开合、虚拟滚动、文件大小、文件标签页、原生右键菜单、排序菜单及刷新后的路径保留。嵌套父目录关闭、收紧的边距及无按钮自动分页已在 App 验证；关闭父目录后的刷新会保留内部已展开目录及其祖先缓存，真实组件回归测试覆盖这一过程。独立 HTML 预览受本地浏览器 URL 策略限制，未完成浏览器可视验收；浅色模式未单独人工验收。
