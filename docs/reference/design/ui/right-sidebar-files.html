交互与边界

  • 默认头部保持一行：项目根目录名在左，搜索、新建文件、新建文件夹、刷新在右。
  • 完整绝对路径保留在标题 tooltip；可见文本使用目录 basename，避免窄栏中只显示路径中段。
  • 点击搜索按钮后在头部下方展开共享 SearchInput 并自动聚焦；再次点击或按 Escape 关闭并清除筛选。
  • 切换项目、新建项目项、外部 reveal 文件时退出筛选，避免隐藏筛选条件继续影响文件树。
  • 不增加搜索服务、全量索引、根目录折叠或新的依赖；筛选仍只作用于已加载节点。
