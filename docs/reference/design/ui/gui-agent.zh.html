OpenProgram · GUI Agent · 当前已实现设计

一个公开入口，一个能力控制器，一份连续上下文。

gui_agent(task) 创建唯一的根函数节点。Harness 控制器根据原始任务、当前资源可用状态，以及之前每一次能力调用中由规划器选择的参数和完整输出，反复选择 computer_use、browser_use 或 vm_use。没有按任务类型预先二分类，也不要求用户先选择 surface。

完整调用架构

函数表单、完整函数表达式和精确节点 Retry 都进入同一个 dispatcher。只有 Harness 控制器决定下一次能力调用；每次结果先写入上下文，再进入下一轮。

每个函数负责什么

gui_agent

唯一公开入口。持有根上下文、可用状态、能力历史、安全上限、终态校验和最终结果。

plan_next_capability

读取完整上下文，选择一个内部能力，或者提出 succeeded、infeasible、failed 终态。

call_capability

绑定 runtime 和隐藏设置，只调用本轮选中的一个能力，并返回完整结果。

computer_use

执行一个 gui_step。该 step 自己完成观察、必要验证、计划和一次动作。

browser_use

对准确的 OpenProgram Page 执行一个有界子任务，完成后把结果交还根控制器。

vm_use

通过 OSWorld 兼容的截图与输入接口执行一个远端 gui_step。

三个 *_use 是内部可追踪函数节点，不是三个公开 Program，也不会再创建一个 gui_agent。

上下文如何保证连续

下一轮不是只看到摘要。它会看到原始任务、当前资源状态，以及之前每一次能力调用中由规划器选择的参数和完整输出。某个 computer_use 的局部函数执行结束后，局部 Python 状态可以销毁；需要延续的信息已经写入根能力历史。下一次 computer_use 所需的 feedback 从上一项 output.next_feedback 取得，由控制器在调用时绑定，不重复写进下一项 input。

能力由 Agent 逐轮选择，不预先固定任务类别

Desktop / Window

  • 前台坐标操作要求目标处于前台。
  • 准确 macOS 窗口可使用单窗口截图和 Accessibility 控件操作。
  • 目标不明确、最小化、其他 Space 或权限不足时返回限制，不回退到前台操作。

Browser Page

  • 绑定提交请求的 OpenProgram 窗口中的准确 Page。
  • 通过 DOM/CDP 操作，不激活标签页、不置顶窗口、不移动系统鼠标。
  • 没有可用 Page 时创建一个后台 Page；只关闭 Agent 自己创建的 Page。

VM

  • 需要 OSWorld 兼容 endpoint。
  • GET /screenshot 读取画面，POST /execute 发送输入。
  • 每次调用后恢复原输入目标和截图 backend，凭据不进入模型上下文。

指定应用窗口的后台控制与可见提示

computer_use 可以选择准确的 macOS 进程和窗口。后端只截取这个窗口，只枚举该窗口的 Accessibility 子控件，并只执行控件声明支持的按压、文本赋值和滚动动作。

目标身份

同时校验进程 ID、窗口 ID、当前窗口几何和控件归属；每次动作前重新读取控件边界。

不抢占前台

不激活应用、不置顶窗口、不使用全局键盘、鼠标或剪贴板，也不移动系统指针。

控制提示层

不激活、不接收鼠标事件的原生提示层跟随准确窗口，并在当前控件边界显示动作图标。窗口被其他应用遮挡或离开当前 Space 时隐藏。

提示层创建或绘制失败不会改变 Accessibility 动作结果。会话退出时关闭标准输入，等待 helper，必要时 terminate、kill 并回收，不能留下孤立进程。

后台 Page 生命周期

01读取 Page inventory只读取来源 OpenProgram 窗口
02绑定或创建复用准确 Page；空 inventory 才创建后台 Page
03建立 WebSession绑定 token、session、frame 和 revision
04Observe / Act / Verify写动作后必须重新观察
05释放或关闭借用 Page 只释放；自建 Page 精确关闭
06清理校验关闭失败返回 page_cleanup_failed 和接手说明

统一结果契约

worker 的 transport completed 只表示结构化结果已经返回和保存，不表示 GUI 任务成功。只有验证完成的 succeeded 才能得到 success=true。

succeeded · true任务完成已有验证证据。
infeasible · false存在需要用户处理的具体阻塞；保留 handoff。
failed · false任务未满足，或超时、无进展、规划协议失败。
cancelled · false宿主取消已经传播，不能被 conclusion 改成成功。

关键文件与职责

OpenProgram · gui_harness_bridge.py注册唯一公开入口、转换隐藏兼容设置、调用原始 Harness、统一最终结果。
OpenProgram · workflow/browser/__init__.py当前后台 Page 子任务、DOM 控制、验证和准确清理。
Harness · main.py公开 Python/CLI 入口，建立能力循环。
Harness · tasks/capability_loop.py可用状态、完整 history、逐轮选择、能力调度、终态校验和结论。
Harness · tasks/execute_task.py单次 GUI step 的观察、验证、计划和动作。
Harness · adapters/mac_window.py准确窗口绑定、单窗口捕获、Accessibility 控件与后台动作。
Harness · adapters/mac_indicator.py不激活、忽略鼠标的窗口控制标志和动作图标。
OpenProgram · product-runtime.json固定经过验证的独立 Harness commit，保证新安装和本机打包使用同一实现。
