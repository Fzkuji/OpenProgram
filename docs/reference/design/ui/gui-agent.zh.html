目标与完成标准

产品目标是在浏览器与原生应用里持续完成任务：组合使用已授权的 UI、代码和文件工具，验证交付物，并始终支持控制。覆盖密集控件、自绘画布、多窗口、对话框、下载、保存、恢复，以及操作系统支持的用户与 Agent 同时操作。

这是原位置改写的唯一 GUI Agent 工程设计。正文规定目标，源码核查和文末状态区分现有能力与仍需实现、实机验收的能力。产品使用说明仍在GUI Agent 使用文档。

验收要求相同模型、相近预算下，明确任务集中的行为能力对齐。本次没有检查所贴视频的完整执行轨迹，不能确定其中 Blender/PCB 成品的具体执行方法，也没有测出 Codex 的量化优势。
  • 唯一公开入口 gui_agent(task)、标准 Agent 配置与共享历史。
  • 持续代码执行、完整 UI 原语、浏览器/本机桌面/VM 适配器。
  • 目标归属、权限继承、执行上限、取消、重启恢复和最终验证。
  • 同模型应用测试；前台或 VM 操作不能代替后台桌面验收。

基础模型训练、复现 OpenAI 未公开内部实现、绕过应用安全限制、承诺兼容所有软件不属于本设计。复杂后台输入仍是必须完成的任务，不能把目标缩减为仅操作 Accessibility 控件。

当前路径与已核实缺口

桥接层只注册一个根入口并解包 Harness 函数。plan_next_capability 将能力历史序列化进 prompt；call_capability 选择内部执行路径。

gui_agent(task)
  -> plan_next_capability(task, history, availability)  # 模型
  -> computer_use(subtask)
       -> macOS window_session
       -> gui_step: observe
            -> verify_step(previous feedback)        # 有反馈时调用模型
            -> plan_next_action                      # 模型
            -> 一个注册动作
  -> 追加输入输出；再次选择

browser_use(subtask)
  -> 自定义循环，每轮 agent(tools=[browser_page], max_iterations=1)
  -> Page/帧检查、动作、可选截图、终态断言

有反馈的桌面迭代通常在额外定位/重试之前已调用三次模型。这是源码结构计数，不是延迟测量。首轮省去上一步验证；AX 窗口动作不使用 OCR/YOLO，其他桌面/VM 路径可以使用检测定位。

macOS 窗口注册表只暴露 window_press、window_set_text、window_scroll 和终态标记；其他文件里的全局键鼠函数不能扩大这个入口。浏览器支持点击/输入/按键/悬停/滚动/选择，但未暴露拖拽与持续脚本入口。

Runtime.exec 已使用 DAG 渲染历史并继承调用方权限限制内部工具，不需要再做 Context Engine。execute_code 每次新建 Python 子进程，无法跨调用保留 UI 对象或变量。

目标架构与职责

一个 gui_agent FunctionInvocation 持有一次标准 Agent 执行生命周期，解析配置、获取资源、暴露工具、执行上限、返回验证结果，不再作为第二个规划器。模型决定观察、UI 操作、正常工具和终态验证。

gui_exec(code) 是普通函数工具。持续 Python 子进程通过限定代理访问资源，可信 broker 持有 Page/窗口对象、权限、租约、坐标映射和回执；模型修改变量不能改变这些。桌面 helper 提供输入/截图，worker 保留 Page 归属与任务控制。

computer_use、browser_use、vm_use 成为兼容边界/内部适配器，新路径不再各自规划子任务。公开表单保持简单；高级配置依次采用显式、环境、默认 Agent 设置。保留 tools=None、tools=[] 和指定列表语义；GUI 工具只在外层授权内加入并排除递归 gui_agent，不能恢复被拒绝的 shell/文件/网络工具。

持续运行器与代码契约

先用 Python，复用现有 Runtime、Harness 和适配器。每次 GUI 调用的隔离子进程保留命名空间并支持顶层 await。broker 内部可用 Playwright，模型只获得限定代理，不拿原始 browser/CDP/AppKit/OS 输入对象。JavaScript 语言适配可后续增加，不是代码操作的必要条件。

复用 backend 进程生命周期与 ToolReturn 图片，采用 GUI 专用强制隔离策略。不改变 execute_code 每次新进程的契约；Python 命名空间限制和 Node vm 都不是安全边界。

原型上限为每段脚本 30 秒、100 次 broker 操作、256 KiB 文本、每次四张图及 provider 像素限制。这是起始参数，不是测得最优值。长时间应用渲染返回异步对象，有界轮询让出执行；超时先撤销写能力再终止子进程。

观察 全量/差分、截图、裁剪、边界 token 绑定目标、generation、帧、几何、映射。

Broker 协议与观察数据

使用限定本次调用的 IPC 连接，JSON 消息带长度边界，图片使用单独有界数据。连接建立时宿主指定 owner 与 generation，生成代码不能选择。请求包含 operation ID、资源对象、方法、参数、观察 token；未知方法和超大消息在执行前拒绝。

# 拟议 broker 消息结构
request = {
  "operation_id": "op-17",
  "resource": "window-handle",
  "method": "drag",
  "observation": "frame-token",
  "arguments": {"path": [[120, 90], [180, 120]], "modifiers": ["Shift"]}
}
observation = {
  "target": {"kind": "window", "handle": "window-handle"},
  "generation": 3, "frame_id": "f-21", "base_frame_id": None,
  "image": {"width": 1600, "height": 1000, "detail": "original"},
  "transform": {"origin_x": 0, "origin_y": 0, "scale_x": 2, "scale_y": 2},
  "controls": [], "capabilities": ["observe", "click", "drag", "keypress"]
}
receipt = {
  "operation_id": "op-17", "state": "applied",
  "last_applied_index": 1, "effect_uncertain": False,
  "observation_token": "new-frame-token"
}

broker 通过现有 execution effects 记录接收与完成，再返回成功回执；接收不证明副作用发生。原生事件派发通常没有事务确认，响应丢失后先观察而非重放；恢复后以租约 generation 阻止旧连接。

回执完成规范化和当前权限检查后，提交准入与撤销通过同一个短锁确定先后顺序。撤销前已获准提交的回执可以在撤销后完成持久化，因为它记录的是已经完成的原语，不授予后续输入权限。锁内不运行适配器、校验函数或数据库调用。动态校验返回后重新检查执行状态、attempt 和取消状态；每次 broker 派发使用独立复制的宿主 owner Context。

无旋转窗口截图的桌面点为 x = origin_x + image_x / scale_x，y 同理；裁剪先映射回父图。一般显示变换使用可逆矩阵，规则由源观察定义。浏览器从截图设备像素映射到 viewport CSS 像素。拒绝超出允许范围或过期变换，不能重复乘除 Retina 比例。

SDK 可以隐藏协议字段，但不能隐藏权限变化。Locator 可在已知目标内重读几何；打开另一应用或在新 origin 操作必须重新通过策略。

macOS：完整输入与后台可行性

保留 ScreenCaptureKit 与 AX。增加稳定签名的完整输入原生 helper，绑定应用身份、窗口和 broker 租约。支持的控件用 AX；画布与键盘流程研究进程定向事件。

本机 SDK 声明了 CGEventPostToPid，AXUIElementPostKeyboardEvent 已弃用。PID 不是窗口 ID；必须验证窗口路由、坐标解释、事件接收和前台/指针保持，不声称 OpenAI 使用该 API。

Harness 的显式测试探针 tests/probe_native_input.py 使用自有 AppKit 测试窗口。在 macOS 15.7.3 arm64 上，原始进程定向鼠标事件到达应用时没有关联窗口；NSEvent 能关联窗口，但后续鼠标坐标错误。实验性 CGEventSetWindowLocation 注记配合包含标题栏的完整窗口 frame，得到预期的点击和拖拽坐标。该 setter 未公开，实验只证明本机可行性，不构成受支持的生产契约。默认探针保留公开 API 对照组，未公开路径需要 --private-window-location。

事件测试窗口不使用剪贴板即可收到普通及 Unicode key-down 字符。独立的 --controls 测试窗口通过实际控件值和 DOM 事件位置，检查原生文本替换、NSButton 动作、本地 WebKit 文本框替换和画布拖拽。Command+A 需要测试应用的标准 Edit 菜单；初次实验缺少该菜单，文本被追加，判定失败。控件几何在 WebKit 加载完成后测量。这些测试只证明少量 AppKit/WebKit 控件行为，不代表已安装应用兼容性、IME、一般快捷键、多窗口隔离或截图坐标映射通过。

更严格的应用身份与双窗口检查表明，不能由上述单窗口样本推断一般后台输入能力。临时签名 App 通过 LaunchServices 启动后，能满足现有 MacWindow 的启动身份校验并取得准确窗口截图。但另一个窗口初始持有键盘焦点时，普通鼠标事件不能使 WebKit 获得焦点，随后网页文本被写入原生输入框；显式添加 Command 修饰后，画布能收到鼠标事件，但键盘文本被写入另一个窗口。这是尚未解决的路由和焦点问题，不是可透明采用的回退方式。探针对两种情况均判定控件验收失败，并在每条回执中检查另一窗口的真实文本，包括输入结束后明确请求的最终状态。生产适配器必须先确认目标焦点，并保持请求的修饰键语义，再发送按键。

前台身份和指针位置只在实验前后采样，不能排除瞬时变化；完整实现门槛通过前，background_input 仍不可用。探索性后台点击分析提供了未公开窗口坐标注记的候选线索，其中关于其他软件的主张不作为已核实事实。

实现第一道门槛：签名 helper、自有 AppKit/WebKit/Electron 夹具、已安装画布应用，另一应用保持前台。记录目标真实状态、截图、前台身份、指针和按键状态。失败意味着后台要求仍未解决，不能以“前台/VM 能做”代替通过。

声明 background_ax、background_input、foreground_input 或不可用。验证过的能力默认后台；前台需要任务/会话策略允许并显示控制，不能静默激活应用。公共 API 不能完成要求时，评估受支持的供应商接入或经过实测的原生方式，该指标继续未完成。

通过 display 身份、窗口原点、比例与裁剪元信息映射截图像素。覆盖 Retina、多屏负原点、窗口移动和比例变化，拒绝过期几何。截图与输入权限分别检查，最小化、安全输入、锁屏、权限框分别返回明确结果。

优先 AX 替换和验证过的按键插入。默认后台和前台文本输入都不以全局剪贴板作为自动传输；使用 AX、Unicode/按键事件或应用局部插入/导入 API。change counter 只能保护恢复，不能防止其他进程在 paste 前替换内容。用户明确要求的系统剪贴板任务使用宿主/pasteboard 仲裁、保留同时发生的用户修改，不承诺并发用户操作时内容正确；浏览器局部 paste 单独限定范围。物理键鼠租约按宿主/会话串行，不能只按窗口。模态 sheet/菜单绑定为子目标或显式新目标，不选择当前最前窗口代替。

浏览器：复用归属并补齐操作

复用 WebUseSessionRegistry、Page token、worker 持有的 WebContentsView/CDP、帧检查和清理。绑定准确的提交 Page 或创建自己拥有的后台 Page，不选择当前活动标签代替；可选 MCP 后端继续作为执行适配器。

提供限定的 role/name、label、text、test-ID、相对 Locator 和 frame 进入，复用 Playwright 可操作性检查和有界等待。每动作重新定位；歧义、语义或归属变化返回 stale-target。数字 ref 只在当前观察有效。

补齐拖拽、多击、修饰键、横向滚动、文件选择/下载、iframe 和弹窗。弹窗按 opener 和准确身份绑定，重新校验目标权限，文件只经授权路径传输；先监听下载/弹窗再触发，避免丢事件。

UI 脚本不暴露原始 page.evaluate、任意 CDP send、cookies、profile 目录或浏览器启动。可信代码可为有界观察读取 DOM。通用 shell/文件/代码工具仍经正常权限提供，显式开发调试能力同样受策略约束；UI SDK 不能成为无限制浏览器控制入口。

Windows、Linux 与 VM 边界

Windows 明确采用当前桌面模式：截取准确 display/窗口，并在前台租约内输入。检测用户接管、桌面切换、锁屏与完整性级别限制。标准控件用 UI Automation，自绘画布用坐标输入。参考产品不声称 Windows 后台控制，我们也不隐式承诺。

Linux X11 与 Wayland 使用不同适配器。X11 可复用输入/截图设施，Wayland 必须有明确支持的 compositor/portal 或远程桌面后端。不支持时返回不可用，不能假定具备 X11 权限。首个 Linux 验收目标是明确的隔离桌面/VM 镜像，不是所有发行版。

保留 OSWorld 兼容的截图/execute 协议，但把目标身份从进程全局 monkeypatch 中移出。每个环境对象持有传输、截图路径、输入状态和租约，凭据留在执行器。检查图片和超时，区分可重试读取与不确定写入，测试两个独立 VM。Docker 是可选 Linux 设施，本机 macOS 和 Windows 宿主操作不要求 Docker。

macOS 锁屏自动操作需要独立审查 OS 授权设计，不能在补齐 UI 时附带新增特权解锁 helper。该门槛通过前，Locked use 明确列为仅参考产品具备；任务记录原因暂停，用户手动解锁后重新观察再恢复。

上下文如何保证连续

模型只使用 DAG 中的正常 user/assistant/tool 消息作为历史。UI 代码、每个操作结果和选中截图记录在相同调用关系中。迁移后移除重复注入的 JSON 历史；兼容返回的 history 由事件派生，不作为第二份事实来源。

分清三个生命周期：Agent 对话、执行命名空间、外部应用状态。继续模型响应不会恢复 Python 对象或应用窗口。安全点记录环境 generation 和资源绑定；压缩保留任务、权限、未满足条件、交付物路径、最后验证状态及不确定副作用。AX/CDP 活对象不能序列化为可移植 checkpoint。

默认返回小型 AX/DOM 差分，使用稳定 broker ID，并允许请求完整快照。缺失基准或差分乱序时返回全量。图片附带 frame/target 与 provider 支持的 detail。按明确保存策略保留近期相关视觉状态、最终证据和失败观察；token 预算与摘要使用共享 Context Engine。

按需裁剪原分辨率图，每张裁剪保存到父图的仿射映射；坐标 SDK 调用必须带裁剪 token 或明确父帧。已有 OCR/检测/zoom 定位作为不确定目标的可选工具，不强制每个 AX/DOM 动作都预处理或额外调用模型。ScreenSpot 类定位只能测一个组件，不能代表长任务完成率。

[S4] [S9] [R1]

延迟、成本与验证策略

优化实际端到端任务。当前结构反复选择能力并逐步验证/规划；目标是一次 Agent 决策执行短的确定性操作组，返回状态再决策。不删除结果验证：确定性检查在执行器完成，视觉歧义和任务阶段结果才需要模型验证。

变化 原因 测量与约束
批量输入和等待 减少逐原语模型往返。 动作数/模型调用、p50/p95 耗时；目标/权限变化停止批次。
AX/DOM 差分与按需裁剪 减少重复像素和文本。 输入/图片 token、误操作率；基准缺失强制全量观察。
复用绑定与命名空间 避免反复连接和创建对象。 连接/截图延迟；generation 阻止旧对象复用。
按需验证 确定性状态检查和最终交付物证明。 误报成功与恢复率不能变差；视觉阶段仍需检查。
有界进展检测 识别重复而不另加规划器。 重复指纹且状态未变时新观察/换策略或明确失败。
模型选择 使用配置模型，独立评估 effort 和小模型替代。 同任务预算配对试验；不能从低成本推断质量。

总耗时拆为模型、截图/编码、broker/输入、应用等待、恢复。记录模型请求、UI 原语、观察、图片 token、重试和人工干预。模型完成 API 调用生成不等于执行器已经应用动作。

测量前不承诺加速倍数。初始性能验收是在完成率不下降的前提下，确定性任务子集的模型请求中位数减少；完整任务集公布耗时分布和失败。复杂视觉任务如能提高完成率，可以使用更多图片预算。

执行权限与隔离

生成的 Python 是任意代码，必须由 OS 隔离。持续子进程使用 GUI 专用 sandbox profile，将外层限制与不可关闭的 scratch/runtime/IPC-only 策略求交。普通 Backend.spawn_spec 路径不足；使用拥有独立临时目录、固定解释器与强制策略的严格启动上下文，要求平台 sandbox 且禁止降级。运行库启动可以读取祖先目录本身的目录项，但不能因此读取其后代文件内容。danger-full-access、宽松继承 override 或 sandbox 不可用都不能关闭该工具隔离；此时 gui_exec 不可用，正常独立授权工具保持原行为。子进程不能直接联网、自动控制桌面、任意读取宿主文件或取得原始 CDP/native 对象；过滤 globals 不是隔离措施。

可信 broker 持有 OS 权限和外部对象，用进程身份与本次调用绑定通道认证子进程，不把可复用全局 bearer 凭据交给生成代码。每次副作用前校验 owner、generation、准确目标、动作、当前用户授权、deadline、取消状态。批次被接受不代表未来新目标都被授权。

正常 Agent 工具分别受权限限制。脚本需要文件/shell 操作时，经显式 broker 工具代理请求正常工具，或返回 Agent 再调用；复用现有 dispatcher 和不可扩大权限的外层请求，不能把旧浏览器路径的特殊 bypass 复制进通用代码运行器。

页面文本和截图是非可信数据，不能授权新应用、修改系统指令或调用受限工具。工具说明与应用能力来自可信宿主。相同授权动作继续使用已有批准，新增应用或扩大副作用按当前策略处理，不给每次无害点击新增确认。

撤销先阻止新副作用、释放已按下的键/按钮并停止脚本，然后清理。私有轨迹有界本地保存，交付物采用明确保存策略；遮蔽安全输入与凭据，测试不自动发布截图或用户数据。

失败、取消与重启恢复

条件 必须行为 验收
观察过期或窗口移动 输入前拒绝，重新观察绑定。 不向旧坐标输入。
弹窗/模态/导航 停止旧状态续执行，发现准确新目标并授权。 不写入其他活动标签/窗口。
批次部分失败 返回已执行前缀与不确定操作，不重放整段。 不重复完成的保存。
输入派发后超时 标记副作用不确定，重试前检查外部状态。 不声称 UI 输入 exactly-once。
用户接管/暂停 阻止写入，安全释放输入状态与租约，保存任务。 恢复先观察，遵守新指令。
worker/helper 死亡 使 generation 失效，只重连归属资源并检查最后副作用。 旧脚本重启后不能继续操作。
拖拽中取消 停止新输入，释放鼠标/修饰键，终止回收运行器。 无按键卡住、孤儿进程或迟到写入。
清理失败 保留主结果，单独报告清理失败。 不关闭借用的用户窗口/Page。
provider 失败 现有有界重试，不重放已执行工具。 模型请求重试不重做副作用。

复用现有 execution-control 安全点、取消和 owner generation，不新增调度器。持久化可序列化资源描述与最后确认的动作回执。崩溃使活命名空间丢失：在脚本边界恢复，重新绑定观察，不承诺恢复 Python 调用栈或重放 UI 写序列。

公开结果仍为 succeeded、infeasible、failed；取消由执行系统 cancelled 状态表示。暂停/审批/接管是可恢复控制状态，不是成功。结果包含原因、未完成条件、最后验证状态及交付物证据，清理失败不能把任务失败改为成功。

默认 App 体验与操作可见性

保留唯一 GUI Agent 表单和注册表达式行为：完整注册函数表达式创建一个 ProgramRun，不多加聊天推理轮；普通文字或代码块仍为普通消息。表单和直接表达式都捕获提交窗口/Page 身份。

运行卡片显示任务、准确应用/Page、后台/前台模式、当前动作、最近观察进度与耗时。展开查看截图、代码批次和逐操作回执，不把每个原语都写进正常对话。保留 adapters/mac_indicator.py 不激活应用的原生提示、归属检查和清理。

停止立即请求取消，界面区分正在停止与已停止。接管阻止写入并说明剩余工作，恢复先重新观察。应用授权提示说明准确应用与范围，按正常策略保存决定并允许撤销；缺失权限分别说明截图还是输入不可用。

显示经过验证的交付物和完成条件，不只显示绿色函数结果。长任务支持阶段进度、用户修正和有界更新。验收使用 /Applications/OpenProgram.app、默认 profile、端口 18100、~/.openprogram，另起 Electron 实例不能代替。

采用两种评估避免混淆：A 相同模型运行当前与新 OpenProgram，隔离执行系统变化；B Codex 产品与 OpenProgram 使用相同模型、任务、OS/应用版本、输入文件和实际预算，比较产品结果。B 的工具能力与隐藏提示不同，必须报告；API 结果不能证明产品能力对齐。

发布必须满足：所有确定性归属/取消/旧帧/隔离测试通过；每项声明的关键能力通过真实应用夹具；验收集无误报成功；完成率相对基线不下降；记录产品对比及限制。建议初始控制目标为同机取消请求后 500 ms 内阻止新动作、1 秒内释放按住输入；必须测量，调整需要明确证据，不能事后为了通过而放宽。

采用、修改与拒绝的方案

决定 原因与结果
采用标准 Agent 与持续代码 一个模型可见循环、普通工具消息、灵活短批次。
采用现有资源和策略边界 保留 Page/窗口归属、签名 helper、DAG、执行控制生命周期。
修改固定逐动作模型验证 原语使用确定性检查，视觉阶段与最终验证仍必要。
保留可选定位 优先 AX/DOM，不确定时裁剪定位；benchmark 代码不作为控制器。
拒绝嵌套自主控制器 每个 UI 工具不再包含能力选择器或浏览器 Agent。
拒绝以 provider 原生协议为前置 普通函数/代码工具支持 Astra 等模型；原生 computer 协议仅在测得收益后适配。
拒绝无限制原始对象 生成代码不能通过 CDP/宿主输入绕过目标权限。
拒绝自动后端/前台回退 失败写入可能已生效，换后端会重复或写错目标。
拒绝任务硬编码 可复用应用 skill 说明验证过的流程，不按任务文本写死程序。
拒绝以 benchmark 代替产品完成 定位分数和 mock 测试不能证明原生长任务可用。
