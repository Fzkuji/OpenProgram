浏览器批注

批注让读者在浏览器标签里标记网页，把这些标记作为一条消息交给 agent。它沿用 Codex App 浏览器里的 Annotate 和 Adjust：指出哪里不对，写下要改成什么，必要时在真实页面上试一下大小、间距或颜色，然后发送。

部分行为
按钮地址栏胶囊里、书签星标左边的 Solar 笔图标；页面处于批注模式时带强调色底。再点一次退出模式。
模式页面顶部居中一条深色提示：“点击元素或拖出方框 · Esc 结束”。指针下的元素描边高亮；页面收不到点击。
元素批注点击后元素得到强调色实线框、右上角带编号的图钉和旁边的卡片：等宽字体的短选择器（h1#firstHeading）、输入框、删除。点击已有批注的元素会打开那条批注。
区域批注拖动至少 8 px 画出强调色虚线框；卡片标题为 region 312×100。
调整元素卡片里折叠在“调整”一行下：大小（字号）、间距（内边距）、颜色。拖动控件即以内联样式在元素上预览；改过的值并入这条批注。
操作条有批注时在底部居中：“本页 N 条批注”、丢弃、发送到对话。
Esc退出模式；未发送的批注、图钉和操作条保留，直到丢弃或发送。模式关闭时，Esc 关闭打开的卡片。
发送一条用户消息：页面，然后按编号列出每条批注的选择器或区域、文字和调整值（font-size 28px → 34px），附一张带图钉的页面截图。随后清除批注和预览样式，模式结束。
丢弃移除所有批注和预览样式，模式结束。
导航地址变化会清除批注。离开标签只结束模式。

决定

决定原因
覆盖层运行在页面里的隔离环境、封闭的 shadow root 中桌面端页面是原生视图，App 窗口画不到它上面，所以描边和卡片只能在页面里。隔离环境让页面脚本看不到也调用不了它；shadow root 和宿主元素的 !important 样式让页面 CSS 改不了它。它和元素、区域选取共用一个环境，开启一个会结束另一个。
App 传入自己的颜色进入模式时从窗口读取 --bg-primary、--border-light、--text-primary、--text-muted 和 --accent-blue，卡片在任何主题下都和 App 一致。宿主只传已知键下的短颜色值。
截图保留图钉截图前卡片、提示和操作条隐藏两帧；描边和编号留着，图和编号列表对得上。
直接发送，不放草稿“发送到对话”就是任务的终点；消息走对话的发送队列，正在运行时排队等候。
优先页面所属对话批注发往打开该标签的 Agent 所在对话，否则是聚焦的对话，否则是上一个对话；只算仍打开的对话。都没有时提示先打开一个，批注保留。
调整用内联样式预览元素自身的内联 !important 声明压过页面规则，也正好是要撤销的那一处；发送、删除或丢弃时恢复元素原有的内联值。
短选择器最多四层，遇到 id 或已唯一即停；跳过生成的类名。agent 拿到的是能在源码里搜到的东西。
浏览器版不提供网页界面用其他源的 iframe 显示页面，无权操作其脚本。按钮留在原位但不可用，提示说明批注需要桌面 App。
