Screenshots

A screenshot tool for people, modelled on Snow Shot: freeze the screen, select a window or area, mark it up, then copy, save, pin, read its text or send it to the chat. It is separate from the Agent's computer_use.

The overlays leave themselves out by their media source ids. Windows are cut at each display's edge.

Marks and toolbar

The marks (lib/annotate/marks.ts) and toolbar (components/annotate) are shared with the composer's image annotator. Marks are kept in image pixels and drawn with widths in CSS px times the image's scale, so a Retina capture and a plain image look alike and the PNG keeps the source size. Mosaic pixelates the picture under it rather than drawing a pattern.

Finished marks are drawn once into an offscreen layer; while dragging, only the mark in progress is drawn on top of it, and a pen stroke drops moves under one pixel. The magnifier and colour picker read the captured pixels directly instead of reading the canvas back.

The toolbar sits under the selection, as in Snow Shot. When there is no room it goes above, and inside the selection when neither side fits (placeToolbar), so a selection along the screen's bottom edge still has its tools.
