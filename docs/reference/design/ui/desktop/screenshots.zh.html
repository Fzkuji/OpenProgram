截图

给人用的截图工具，照 Snow Shot 做：定格屏幕，选窗口或区域，标注，然后复制、保存、贴图、识别文字或发送到对话。它和智能体的 computer_use 无关。

截取与覆盖层

部分做法
入口全局快捷键 CommandOrControl+Shift+2、托盘菜单项、输入框的 + 菜单（screenshot.start，等菜单关上再截）。
画面desktopCapturer 按每个显示器的像素尺寸截屏，用 display_id 对应；BGRA 位图经 IPC 交给覆盖层，只有覆盖层页面能读。
覆盖层每个显示器一个无边框窗口，screen-saver 层级，macOS 上是不激活的 panel，App 不会跳到前面。它加载 /menu-overlay/screenshot，用完隐藏不关闭，下次立刻打开。页面画好画面后才显示；指针所在的显示器接收键盘。
多个显示器每个覆盖层只在自己的显示器上选；在一个上开始选，其他的清空。

窗口吸附

平台来源
macOSCGWindowListCopyWindowInfo，第 0 层，从前到后，单位是点。
WindowsEnumWindows，按显示器感知 DPI；跳过工具窗口、不激活窗口和被隐藏的窗口；用 DWM 的边框范围；像素用 screenToDipRect 换成 App 坐标。
Linux，X11_NET_CLIENT_LIST_STACKING 加 _NET_FRAME_EXTENTS；像素除以显示器缩放。
Linux，Wayland没有：Wayland 不提供其他窗口的位置。单击取整个显示器。

覆盖层按自己的媒体源 id 把自己排除。窗口在每个显示器边缘截断。

标注与工具栏

标注（lib/annotate/marks.ts）和工具栏（components/annotate）与输入框的图片标注共用。标注按图片像素保存，线宽用 CSS px 乘图片缩放来画，所以 Retina 截图和普通图片看起来一样，导出的 PNG 保持原尺寸。马赛克是把下面的画面像素化，不是画图案。

工具栏和 Snow Shot 一样放在选区下方。下方放不下就到上方，两边都放不下就放进选区里（placeToolbar），所以贴着屏幕底边的选区也有工具。

文字、贴图和结果

部分做法
OCRmacOS 用 Vision；Windows 经 PowerShell 用 Windows.Media.Ocr，去掉中日韩字符之间的空格；Linux 用 tesseract。识别框画在画面上，文字列在旁边。
贴图无边框置顶窗口，放在选区原来的位置。拖动时由 App 移动，以指针为中心缩放（0.1–5 倍），按修饰键调透明度（0.25–1），右键是系统菜单。
发送到对话向当前 App 窗口发 screenshot:attach，当前输入框像收到拖入的文件一样排上这张 PNG。
保存保存对话框默认在“图片”文件夹，文件名 Screenshot YYYY-MM-DD HH.mm.ss.png（中文界面是 截图 …）。
