设置导航

设置使用所有带列表列的页面共用的页头和二级导航栏。列宽沿用现有侧栏，不支持拖动调整。

列展开收起保存于页头
分类--sidebar-width − 1px49pxsettingsNavOpenManagePageHeader：导航栏切换按钮，然后是“设置”
内容剩余宽度；控件换行相同不保存一个页面标题；记忆不加重复标题

分类

通用、外观、LLM Provider、记忆、网络搜索、浏览器、语音、运行环境、频道、导入对话、Token 用量、系统。链接、图标、选中状态和键盘顺序都来自这一个数组。

部分规则
切换按钮原生按钮，带 aria-expanded、aria-controls 和明确名称，图标与下方分类图标同轴
窄窗口低于 760px 且没有保存选择时默认收起，缩窄时收起但不保存。变宽绝不展开：以保存的选择为准。
行y 位置、32px 行高和 1px 间距与主侧栏的行相同
标题“设置”和内容标题使用 --fs-title（18px），行高 1.2，避免下伸部被裁切

LLM Provider 是单列页面，没有自己的列表列：它的列表、添加供应商和每个供应商的页面见供应商管理。

参考与不做的事
来源用途
WAI-ARIA APG Disclosure按钮语义和 Enter 或 Space。不涉及列宽和标题。
MDN aria-expanded状态与可见列一致；不用 aria-pressed。
不做拖动调整列宽、断点覆盖用户选择、改动记忆、Provider 或模型数据、改动主侧栏
验收
  • 没有单独的全局设置顶栏。
  • 分类行与主侧栏前几行对齐；收起时第一个图标的 y 不变。
  • 分类顺序、URL、图标、选中状态和键盘顺序一致。
  • 记忆没有重复标题。
  • 图标操作带 aria-label。
