分类

十二个分类分成四组，按读者要找的东西命名。链接、图标、选中状态和键盘顺序都来自这一个数组。每组有一个 RailGroupLabel；导航栏收起时隐藏组名，图标排成一列。

组分类
个人通用、外观
模型与能力模型服务、Token 用量、记忆、网页搜索、语音
电脑与连接机器、浏览器、消息渠道
数据导入对话、版本与更新

设置放在它所改变的东西的页面上，所以没有大杂烩页面。Codex 和 Cursor 的设置导航也这样分组：平铺列表上方加不显眼的组名。

参考与不做的事
来源用途
WAI-ARIA APG Disclosure按钮语义和 Enter 或 Space。不涉及列宽和标题。
MDN aria-expanded状态与可见列一致；不用 aria-pressed。
不做拖动调整列宽、断点覆盖用户选择、改动记忆、Provider 或模型数据、改动主侧栏
验收
  • 没有单独的全局设置顶栏。
  • 分类行的行高和间距与主侧栏相同；组名只在导航栏展开时显示。
  • 分类顺序、URL、图标、选中状态和键盘顺序一致。
  • 记忆没有重复标题。
  • 图标操作带 aria-label。
