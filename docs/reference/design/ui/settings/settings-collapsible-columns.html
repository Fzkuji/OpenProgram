Categories

Twelve categories in four groups, named by what the reader is looking for. Links, icons, active state and keyboard order follow this one array. Each group has a RailGroupLabel; a collapsed rail hides the labels and keeps the icons in one column.

Acceptance
  • No separate global Settings topbar.
  • Category rows have the main sidebar's row height and gap; group labels show only when the rail is expanded.
  • Category order, URLs, icons, active state and keyboard order agree.
  • Memory has no duplicate title.
  • Icon actions carry aria-label.
