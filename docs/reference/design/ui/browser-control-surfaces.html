Wording rules for this document

Do not invent names or metaphors. Say what the control is, where it sits, and what happens when you click it.

Use a technical word only when needed, and explain it in the same sentence. A reader should understand a button label without asking what it means.

When this is pointed out, rewrite all similar copy in the same pass. Do not praise the request. Do not repeat a summary of the same point in several places.

What the buttons do

I will operate asks the Agent to stop clicking and typing on this webpage. It does not reload the page. It is not the browser Stop for a document that is still loading. Until the program confirms the pause, do not say the Agent has stopped. After it confirms, you type and click; the Agent does not.

Continue Agent is you telling the Agent it may click and type again. A timeout, a reconnect, or opening a restored tab does not do that for you.

Show actions / click marks draws short marks on the last places the Agent clicked or typed. They do not change what the webpage receives.

Operation history lists recent Agent steps for this webpage. It is a log. It does not undo those steps.

Semi-transparent buttons still hide whatever is under them. Empty space around them does not block clicks on the webpage. To reach covered content, drag the small button elsewhere or fold the actions.
