承诺与心跳：agent在正确的时刻主动开口

现在的agent只在被问的时候回答。这个设计让它记住对话里出现过的承诺（"周三交rebuttal"、"下周换服务器密码"），在到期的时刻主动提醒你。两个机制一个循环：承诺是状态，心跳是钟。设计正文见commitments-and-heartbeat.md，本页是给人看的。

01用起来是什么样

周一 · 正常聊天

你rebuttal我周三之前必须交，实验今晚先跑上
AGENT好，实验已经在跑了。
（后台：记忆整理时提取出承诺"周三交rebuttal"，带原文引用）

周三 08:00 · 心跳自动触发

AGENT · 主动消息今天是rebuttal的截止日（你周一说的）。实验昨晚跑完了，要我先把结果表整理出来吗？
你已经交了
AGENT（后台：下次整理时该承诺标记done，不再提醒）

不建新管道。五个环节里四个是现成子系统，新写的只有提取规则和提醒判断。

04四条防打扰规则（不做成唐僧是设计目标）

没事不说话

心跳发现没有到期/逾期承诺就静默结束，不发"今日无事"这种噪音。

每条承诺每档只提一次

到期时提醒一次，逾期到配置的间隔再提一次，不是每次心跳都念。提醒状态记录在承诺上。

安静时段

默认23:00–08:00不发，攒到下一个允许的心跳。

一个开关

proactive.heartbeat：daily（默认）/ hourly / off。关掉后提取照做（memory status里能看），只是不推送。

05明确不做的

不做任务管理器

没有子任务、优先级、项目分组。就是一张自己会写自己的带引用日期清单，比todo app多的只有"不用你自己记"这一件事。

不自主执行

心跳只提醒不动手："你说过要换密码"在范围内，自己跑去换密码不在。执行永远是你发起的正常轮次。
