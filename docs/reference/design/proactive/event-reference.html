OVERVIEW

文档范围与读取方式

事件层是进程级 EventBus。源构造 frozen Event 并发送到总线，消费者按类型订阅；gate 事件在发送方线程内同步执行。registry 给出名称、kind 和 payload 说明，调用点用于确认事件生产。名称、数量和源码路径以当前 checkout 为准。

状态：当前调用 表示 registry 与 emit/bridge/gate 路径均可定位；仅注册 表示当前只声明在 registry，不能据此声称运行时必然产生。

GUIDE · OBSERVE

观察：订阅当前事件

订阅是异步观察接口。handler 的返回值不改变 emit 方。

from openprogram.events import get_event_bus

def on_file_changed(event):
    print(event.payload["path"], event.metadata.get("session"))

unsubscribe = get_event_bus().subscribe(
    on_file_changed, types={"file.changed"}
)
GUIDE · GATE

同步 gate：工具和轮次停止判断

registry 中的 gate 类型是 tool.before 和 turn.stop。gate 返回空值表示允许，返回字符串表示拒绝并携带理由；tool.before 也有 register_tool_gate 兼容入口。

from openprogram.events import get_event_bus

def guard(event):
    if event.payload.get("tool") == "bash":
        return "policy denied this tool call"
    return None

remove = get_event_bus().subscribe_gate("tool.before", guard)
执行约束：gate 在同步路径上运行；避免 LLM 调用和慢速 I/O。当前 bus 对异常、软超时和同类型重入按 fail-open 处理。
DEBUG

事件日志

进程级单例总线为 typed dispatch 写入 JSONL：带 session 且对应目录存在时写入 ~/.openprogram/sessions/<sid>/events.jsonl，否则写入 ~/.openprogram/logs/events.jsonl；超过 5 MB 时轮转。gate verdict 写在同一条记录的 gate 字段中。

tail -f ~/.openprogram/logs/events.jsonl
常见顶层 turn 的 registered typed events 包括 user.prompt_submitted、turn.start、model.response_started、tool.before、tool.after、model.response_completed 和 turn.end。实际顺序随失败、取消、工具调用和 stop hook 分支变化。
