行为

项目输出依据
首屏视频静音循环的 1280×720 导览视频（约 3 MB），带固有尺寸和取自片头的 JPEG 封面。每个主题一份；一小段内联脚本按 data-theme 选一份，只下载这一份。开启减少动态效果时显示封面和播放控件，不自动播放。优化 LCP、响应式图片
落地页图片和文字明确宽高。次要文字达到 WCAG AA。只有图标的复制按钮带无障碍名称。标题里的 program 用 App 的蓝紫品牌渐变。Lighthouse
语言配对相同且互指的 en、zh-Hans、x-default 链接，英文作回退，与 canonical 同源同基路径。未配对页不输出。本地化版本
Canonical指向自身；语言切换不变
面包屑每个内容页一个 BreadcrumbList：OpenProgram Docs → 当前页。文档根没有。由标准库序列化并转义 <。面包屑数据
发布订阅一个 application/atom+xml alternate，指向 https://github.com/Fzkuji/OpenProgram/releases.atom不新增发布服务

拒绝：为富结果改成 SoftwareApplication，因为没有评分或报价数据；统计、跟踪、Cookie 横幅、新运行时依赖、CDN 或托管变更。GitHub Pages 缓存头不受仓库控制。
