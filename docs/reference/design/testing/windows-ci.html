Windows CI completion

The native x64 and ARM64 jobs execute platform contracts and the complete unit suite with four workers. A completed test count does not prove that error reporting and process shutdown finish.

Failure diagnostics

Windows Python output is unbuffered and unit results include test names. A process-wide traceback deadline covers reporting and shutdown as well as test execution. The test step and job also have finite execution limits. Failed tests retain their nonzero exit status; no tests are removed or accepted as passing.

Acceptance

Both native architectures must complete the full unit suite and platform contracts. An intentionally blocked diagnostic process must emit its Python stack and exit unsuccessfully. Ordinary failed tests must emit their details and exit unsuccessfully.

Implementation status

Diagnostic validation and native Windows root-cause analysis are pending. Existing runs reach the error-summary stage without completing.
