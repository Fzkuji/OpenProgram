2. 字段与上下文边界

输入保存位置进入模型上下文的方式
Display name / Agent IDagent.json作为运行身份元数据；ID不作为自然语言指令注入。
Channel identity / mention patternsagent.json.identity用于消息路由和外显身份；pattern本身不写入模型提示。
Provider / model / effortagent.json由Runtime创建模型调用时解析；凭据不经过Agent配置。
System promptagent.json.system_prompt每次新session按固定优先级注入。
AGENTS.md / SOUL.md / USER.mdagents/<id>/workspace/按workspace loader规则加载；UI显示来源和最后修改时间。
Session scope / resetagent.json只影响session key与生命周期，不作为提示文本。
优先级：系统运行约束 → Agent system prompt → workspace规则 → 当前项目规则 → 会话消息。UI只展示OpenProgram实际实现并可追踪的层级，不允许用户通过System prompt编辑系统安全约束。

3. 会话和workspace合同

Workspace

可编辑的持久文件

显示完整路径、文件用途、最后修改时间和打开入口。workspace是Agent默认工作目录与指令来源，不宣称为安全sandbox。

Sessions

独立的运行历史

配置页只显示数量、存储占用与“Open sessions”入口。具体消息、DAG和重试仍在Chats页面。

Reset

只影响后续路由

修改scope或reset不迁移、合并或删除现有session。新消息按新策略选择session，旧session保持可查看。

Delete

不可恢复的目录删除

删除确认需要显示Agent ID、workspace路径和session数量。默认Agent不可删除；失败后不得部分更新默认指针。

4. 必须设计的状态

状态页面行为
Provider未配置模型字段显示Unavailable和Provider设置入口；允许保存其他分页，但Agent状态标记为Cannot start。
模型已删除或不再支持effort保留原值并标记Missing/Unsupported；用户明确选择新值前不自动替换。
workspace文件缺失显示Missing和Create入口；不在读取页面时静默生成。
workspace文件不可写允许只读打开；编辑操作禁用并显示具体路径和系统错误。
session scope变更显示“仅影响后续消息”；不提供自动合并历史。
保存失败保留表单值和dirty状态；错误靠近对应字段，同时在页头提供总错误。
并发修改阻止最后写入覆盖；显示服务端版本与本地变更，不自动合并prompt正文。

5. 最小接口合同

操作接口职责非职责
Create校验ID唯一性，创建agent.json、workspace、sessions和bootstrap文件不复制其他Agent的sessions或凭据
Patch core fields校验model、identity与session字段，按版本更新不修改Programs、Skills或MCP实体
Read workspace metadata返回允许显示的文件、路径、修改时间、可写状态不自动把文件正文并入Agent列表响应
Set default原子切换唯一默认Agent不删除旧默认Agent
Delete校验非默认Agent后删除其配置、workspace和sessions不删除任何全局能力实体

6. 验收条件

  1. Agent ID创建后只读，Display name和Channel identity可独立编辑。
  2. 模型列表严格由所选Provider返回；凭据只在Provider设置中管理。
  3. System prompt与workspace文件分开显示、分开保存，页面明确展示上下文来源。
  4. 四种session scope的隔离语义与Runtime现有枚举完全一致。
  5. 修改session策略不迁移或删除历史session。
  6. 删除确认列出workspace和sessions影响，默认Agent不可直接删除。
  7. 所有失败状态保留用户未保存输入，不使用成功toast替代字段错误。
