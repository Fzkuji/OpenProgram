Evidence and alternatives

React callback dependencies require reactive setter dependencies. Reuse the existing session stores; do not remount the whole composer to conceal stale callbacks.

Python executor lifecycle explains why context-manager shutdown waits. Explicit non-waiting shutdown permits early return but cannot cancel already running sync requests. Preserve transport deadlines rather than introducing a new async provider API.

Jina search requires authenticated access in the tested endpoint. Availability must reflect credentials rather than unconditional success. Registration uses stable provider names; runtime availability is checked for each call.

Regression checks use the production hooks, socket request helper, tool executor and resolver. Product docs describe explicit search off and per-session profile persistence. Existing verification failures use URL-safe filesystem conversion and regenerated package READMEs.

Provider schema visibility

Explicit Web Search intent ships its schema in the provider request, including search-only chats. Promotion copies the selected tool and preserves the shared deferred registry and Agent exclusions. Cold-session and frozen-turn regression checks cover the provider split.
