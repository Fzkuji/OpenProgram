Current design

Retain checkpoint metadata, reference counts, control-message budgets, content hashes and execution ownership checks. Tool results no longer have a 64 KiB rejection threshold; blob storage no longer rejects at 1 MiB. The 1 MiB value remains a display-page or producer-chunk target. This repair does not change model input policy.

Implementation status

Implemented and verified: full-size image/text persistence, fresh-store restoration, completion-record reference reuse and corruption detection. The implementation gate records 1,422 passing tests and one skipped test. Not implemented in this change: unified model-facing previews and on-demand reads, or image-region inspection; existing capabilities require audit first. Existing reconciliation_required executions are not automatically repaired, and the original session screenshot has not been rerun.
