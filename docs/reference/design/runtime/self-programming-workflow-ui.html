2. Programs → Applications 网页原型

Programs不再增加单独的Workflows分类。一级类型只有Functions、Agentic Functions和Applications；Self-Programming Workflow是Application的一种实现形式，在详情中显示源码类型、Git、依赖关系和测试状态。

分类合同：分类列表只显示Functions、Agentic Functions和Applications三种互斥类型，不增加All Programs汇总入口。默认内容区同时显示这三类的完整列表，左侧类型只负责定位对应段落，不能把另外两类从页面隐藏；搜索跨三类匹配名称与说明。Favorites是独立的用户视图，只显示已收藏项目。Agent能使用哪些Programs由独立的 Agents → Tools & Programs 配置，不在此页显示Profile或权限状态。

3. 网页交互合同

操作或状态网页行为
打开Programs内容区按Functions、Agentic Functions、Applications顺序显示三段完整列表；不要求先选择类型，也不增加All Programs入口。
选择类型左侧类型保持三项稳定，点击后滚动并定位对应内容段落，不隐藏其他类型。
选择Favorites进入独立收藏视图，只显示已收藏的Programs。
配置Agent访问范围跳转到独立的Agents配置页；Programs不保存Agent、Profile或会话级权限状态。
搜索在默认内容区跨三类匹配名称与description；收藏视图只搜索收藏项，不搜索run历史或Git正文。
选择Application或关系节点切换详情并把项目写入URL；刷新后仍定位同一项目。
Show transitive默认只显示直接Calls / Used by；间接依赖使用虚线和缩进，不解释为所有权。
Run tests立即显示Testing并禁止重复触发；结果严格绑定仓库路径与完整HEAD。
HEAD变化旧测试状态立即恢复Not checked。
查看实际调用进入对应会话DAG；Programs不复制run历史。
窄屏按分类导航、三类列表、详情的顺序纵向排列。

Run历史属于会话和DAG，Git历史属于Git。管理网页不创建revisions、active pointer、workflow version id或持久测试数据库。
