Decisions

ChoiceWhy
Read the conversation the way its own agent resumes itClaude Code's resume follows the parent chain from the newest record; Codex replays the rollout in order. The imported conversation is then the one the user last saw there, not abandoned branches.
Write native nodes, not an attachmentSearch, export, rewind and continuing the conversation work unchanged. Tool calls whose tools do not exist here are replayed to the model as text.
Ids derived from agent, source id and turn indexWriting a turn twice is a no-op, so a grown source appends in place. Same principle as OpenCode's import, which keys an imported session by its original id.
Ledger with last fingerprint and headUnchanged sources are skipped without a parse. A rewound source, or a session continued here, becomes a new session, so nothing already here is rewritten.
Recency from the last message, not file size or mtimeA running agent keeps appending bookkeeping records to a transcript whose conversation has not moved.
Credentials removed with the request-redaction shapesAn imported turn is replayed to whichever model continues it. The high-precision shapes from models/providers/utils/redaction.py catch keys and tokens without rewriting prose that only mentions a key or a token; export's broader rules would. A title is cleaned before it is cut to length, since a key cut short no longer matches its shape; the listing's scan cache keeps its first message and titles cleaned too. Sign-in files are never opened.
Placed in the folder's projectSame as opening that folder here; the original cwd stays in imported_from.cwd.
--dry-run beside --list--list shows every transcript and its state; --dry-run shows only what the same command would create or append to. It runs plan_imports, the same decision the import makes, so a rewound source shows as a new conversation, not an append.
Codex app conversations synced, not importedThe Codex app's and CLI's threads come in by themselves through codex_sync.py, which reuses this reader, writer and ledger but links each conversation to its Codex thread and appends turns made in the app, skipping turns OpenProgram ran on it; see Harness engines.
Synced conversations' projectsSynced conversations of every app get their folder's project as an import does, except in a folder the app made for one chat (the Codex app's ~/Documents/Codex/<day>/…, the Claude app's scratch workspaces) a temporary one, or a folder whose project the person removed, which stay in the default project. One synced before its folder got a project moves there once.
Messages sent from hereThe person's own messages reach Codex, Claude Code and DeepSeek Harness as typed; messages that came through a channel, the owner's there included, keep OpenProgram's speaker envelope so the agent can tell who spoke. An envelope an earlier version sent is unwrapped when the transcript is read, and once in conversations already synced, their title too
PicturesA picture the person sent in the app (Claude Code's base64 image block, Codex's data: image) is kept in the conversation's media/ and shown where it sat, as a picture sent here is, and sent again when a turn here reads the message. One whose bytes the transcript lacks stays [image]. Conversations synced before get theirs once, a few per sync.
Pictures in peersCline keeps Claude Code's image blocks and drops Codex's pictures; Hermes Agent shows [image] and drops Codex's
The Claude app and DeepSeek Harness synced tooapp_sync.py brings in the Claude app's Code tab conversations and DeepSeek Harness's (deepseek_harness.py reads its zstd event log) with the same ledger, and appends turns the app adds after whatever was said here; a conversation rewound in the app is left as it is here. Conversations started with claude in a terminal (entrypoint: cli) come in too.
They continue in their agentA DeepSeek Harness or Claude conversation is linked to its session on that agent's engine; the turns the engine ran are known by the id of their last assistant message or record and skipped.

Implementation status

  • Only the default homes (or $CLAUDE_CONFIG_DIR, $CODEX_HOME) are scanned; a copied folder from another machine cannot be named on the command line.
  • A session imported before credentials were removed keeps what it holds until its source grows; then only the last imported turn is rewritten clean. A turn's fingerprint is taken from its text as read, so redaction never turns such a source into a duplicate session.
