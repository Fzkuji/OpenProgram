Agent 配置框架

Agents页面管理可运行Agent的身份、模型、指令、能力范围和会话策略。Programs、Skills与MCP仍是独立实体目录；Agent只保存对它们的引用和访问策略，不复制实体内容。

1. 三层职责

Global entities

Programs / Skills / MCP

系统中实际存在、可安装、可编辑或可连接的能力实体。

  • 实体源码、schema、连接状态和版本
  • 由各自的全局页面管理
  • 不保存某个Agent的模型或会话设置
Agent configuration

Agents

某个Agent使用什么模型、指令、能力和会话边界。

  • 保存实体引用与访问规则
  • 创建独立workspace与sessions目录
  • 一个页面内分区编辑，统一保存
Conversation override

当前会话

只覆盖本次会话，不改写Agent持久配置。

  • 临时模型、thinking effort或工具范围
  • 明确显示“继承Agent”或“已覆盖”
  • 新会话重新读取Agent配置
边界：Agent配置不保存120个工具的schema，不复制Skill正文，不保存MCP凭据。Runtime根据Agent规则解析当前可用实体，失效引用在页面中标记，但不静默删除。

4. 页面状态与失败行为

Editing

本地草稿

任一字段变化后显示Unsaved changes；切换Agent或离开页面前提示保存或放弃。保存请求只发送变更字段。

Conflict

版本冲突

如果配置在其他窗口更新，拒绝覆盖并展示Reload / Review changes。初期后端若无版本字段，需要先补充乐观并发合同。

Missing reference

实体失效

已删除Program、Skill或MCP服务显示Missing，不自动移除引用；用户确认保存后才能清理。

操作预期行为
Create Agent创建配置、workspace与sessions目录；成功后选中新Agent并停留Overview。失败时保留表单。
Set as default原子更新默认指针；至少保留一个默认Agent。
Duplicate复制配置和workspace模板，不复制sessions、历史消息或凭据。
Delete明确列出将删除的配置、workspace和sessions；默认Agent不可直接删除；删除前要求输入Agent ID。
Save当前分页的修改可以批量保存，但成功后所有分页读取同一AgentSpec版本。
窄屏Agent列表收为顶部选择器；分页可横向滚动；编辑区单列，不出现横向页面滚动。

5. 数据与实现边界

Agents UIsix configuration sections
→
Agent APIcreate / read / patch / default / delete
→
Agent manageragent.json + workspace + sessions
责任决定
持久配置agent.json保存AgentSpec；workspace文件继续独立保存，避免把大段文件内容塞进AgentSpec。
实体引用Programs、Skills、MCP只保存稳定名称/pattern和policy，不保存schema或凭据。
运行解析每次新会话或配置变更后由统一Runtime registry解析；页面不实现第二套resolver。
凭据Provider与MCP凭据由各自全局配置管理；Agents页面只选择引用，不读取或复制secret。
历史会话历史属于Agent sessions；Programs运行历史属于聊天DAG；配置页只提供进入相应页面的链接。

8. 框架验收合同

  1. Agents页面存在一个明确的创建入口；创建成功后可配置全部六个区域。
  2. Overview、Model & Instructions、Programs、Skills、MCP、Sessions均使用同一Agent ID和同一持久版本，不形成多套配置对象。
  3. Programs、Skills和MCP实体仍由各自全局页面管理；Agent页面只保存引用与策略。
  4. 完整实体schema、Skill正文和MCP凭据不写入Agent上下文；Runtime按需解析。
  5. 默认Agent、失效引用、未保存修改、保存失败和并发冲突均有独立可见状态。
  6. 删除确认明确说明配置、workspace和sessions会永久删除，且不能直接删除当前默认Agent。
  7. 键盘可用Arrow Left/Right、Home、End切换分页；焦点、保存状态和错误信息可访问。
  8. 窄屏仍可选择Agent、切换分页和完成表单，不依赖hover。
