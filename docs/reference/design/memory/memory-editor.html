Memory reading, editing and history

Data and failure handling

Owner-authorized Memory endpoints read bounded Git history restricted to topic Markdown. Compare submitted base content under the existing write lock to reject stale edits. Return canonical saved text because normalization may alter source. Show only errors and Git warnings inline; no saving or saved indicators. Preserve drafts locally across navigation and reload; serialize saves per file. Never mark newer typing as saved by an older response.

Acceptance

Topics and Core open in preview; no Save button. Typing automatically persists, survives switching files, and creates a visible Git entry. Undo reverses individual edits; History restores a chosen version. History supports older pages and parent diffs. Rejected/conflicting saves preserve drafts and show an error. Path and revision inputs cannot escape Memory. Existing source validation and rendering remain intact.

Source links and sidebar

Archive hides a session without expiry or capacity deletion. Deleted original sessions have unavailable links, labelled Original session deleted; no additional source copy is made for deletion. Existing Memory source storage is checked before exposing content. Memory navigation and refresh controls reuse the primary sidebar row and icon-button styles.
