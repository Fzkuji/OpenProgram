Status definitions

  • Candidate only: code or reports exist, but there is no single accepted integration head with final review evidence.
  • Main-local: committed on local main but not on origin/main.

  2. Finish partial plans on their own branches. Complete JSON Tasks 6–7 and credential Tasks 3–5 before integration; create one accepted resource-governance head; finalize commitments/heartbeat separately.
