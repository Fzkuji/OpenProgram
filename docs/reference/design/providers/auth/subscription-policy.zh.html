订阅政策

方式规则
API厂商的官方 API，用本人从厂商拿到的 key，按 API 账户计费
套餐厂商自己的程序，作为外部 Agent 运行：Codex app-server、Claude Code、经 ACP 的 Gemini CLI（第三方 Harness）。由程序登录并和厂商通信，OpenProgram 只和程序通信
绝不OpenProgram 自己使用套餐登录、冒用官方客户端身份（user agent、originator、client id），或调用内部端点

原因

套餐的登录属于厂商自己的客户端。别的客户端冒充官方客户端发送它，违反厂商条款，厂商会封停背后的账号（T3 Code，见同类项目）。

Anthropic 只通过官方 API 加 key 接入；Claude 订阅凭据一律拒绝（provider_policy.py）。

已撤下

Provider id原来改用
openai-codex用 ChatGPT 登录调用 Codex 后端Codex Harness；或 openai 加 API key
github-copilot用 GitHub 登录调用 Copilot 的聊天 API模型厂商的 API key
gemini-subscription、google-gemini-cli、gemini-cli用 Google 登录调用 Cloud Code Assist（cloudcode-pa）经 ACP 的 Gemini CLI；或 gemini 加 API key
xai-subscription用 Grok 登录调用 Grok CLI 的聊天代理xai 加 API key

一起去掉的：Codex 和 Copilot 的额度读取器（wham/usage、copilot_internal）、订阅模型目录及其刷新、Codex CLI 登录导入、providers configure 向导，以及按 provider 的 runtime 子类。

已保存的设置

WITHDRAWN_PROVIDERS 里的 id 不会被列出、提供或登录。配置项、Agent 或对话里写着它时，按不存在的 provider 跳过；models.dev 里它的行也被丢弃，所以模型选择器里不会出现。

Codex 套餐额度

只来自 Codex 自己：app-server 在进程启动时的 account/rateLimits/read，之后按同一个 CODEX_HOME 合并每条 account/rateLimits/updated（rate_limits.py），以及它自己的 rollout 文件里 token_count 事件带的 rate_limits。

只算套餐的 codex 额度族，较新的读数为准。读数存在 harnesses.db，显示在第三方 Harness的用量页。不向 ChatGPT 发任何请求。
