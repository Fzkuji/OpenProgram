# Source

[figures4papers](https://github.com/ChenLiu-1996/figures4papers) by Chen Liu, copied
unchanged from commit `b709de17da7e8f9a72e51a5de5bced924a01eeab`.

They are licensed under Creative Commons Attribution-NonCommercial 4.0 International
(`LICENSE` in this folder): keep this notice, and do not use them commercially.

To update, copy the same files from a newer commit and change the commit above.
`../../../templates/paperfig.py` implements the helpers that `references/api.md` specifies;
when the API changes upstream, change that file with it.
