# metaanalysis tasks

The `meta_analysis` task of auto_research (`tasks/metaanalysis/`). It pools the numbers that published works report for one question and grades how certain the pooled answer is: dual blind screening with an agreement figure, extraction in which every number carries a verbatim quote, a risk-of-bias checklist for ML experiments, random-effects pooling, and a GRADE summary of findings. field_survey finds and screens works and literature_table tabulates them; neither pools results across studies or grades certainty.

Learned from GRADEpro (certainty of evidence, summary-of-findings table), DistillerSR and Rayyan (dual blind screening, extraction with an audit trail) and Dr.Oracle (evidence strength).

## meta_analysis

| Item | Contract |
| --- | --- |
| Signature | `meta_analysis(paper_dir: str, question: str, works: str = "", screeners: str = "2", out_dir: str = "") -> str` |
| Purpose | The author gets the pooled effect of a method over its comparator across published studies, with heterogeneity, a forest plot and a certainty rating, and every number traceable to a quote. |
| Input | `paper_dir`: the project's Git repository. `question`: the review question, naming the method, the comparator, the setting and the metric. `works`: arXiv ids, DOIs or PDF paths, comma-separated, or one `.bib` file (in the project or absolute); empty uses every entry of the project's .bib files (`library.resolve.entries`) and the core and adjacent papers of `workflow/surveys/*/*/survey.json`; duplicates (same arXiv id, DOI or a close title; an arXiv DOI counts as its id) are kept once, at most 60. `screeners`: `2` or `3` screeners on the caller's model, or 2 to 3 model names, comma-separated, one per screener. `out_dir`: default `<paper_dir>/drafts/meta_analysis`. Not a Git repository, an empty question, a bad `screeners`, an id that is not an arXiv id, DOI or PDF, a missing .bib, or no candidate raises `ValueError`. |
| Candidates (code) | Titles and abstracts from the arXiv API (`survey.search.arxiv_ids`) and OpenAlex by DOI (which also gives an arXiv id); a .bib entry with neither id gets one from `reading.reader.arxiv_of`; a PDF's first page stands in for its abstract. |
| Screening | Screener A (strict population, intervention, comparator, outcome), B (a methodologist: does it report a poolable numeric comparison) and, with three, C (a sceptic) each decide include or exclude for every work from its title and abstract, in batches of 15, blind to each other, with a reason and a quote. `check_screen`: a decision whose quote is in neither the title nor the abstract is dropped, and works a screener left out are asked once more. Cohen's kappa (`qualitative.agreement.kappa`) and percent agreement per pair of screeners over the works both decided, and their mean; disagreements are listed for the author. A work any screener includes, or none decided, goes to full text. |
| Full text (code) | arXiv HTML with its tables first (`reading.reader.work_text`), then the arXiv LaTeX source or PDF (`deepread.source.get_work`), and for a work without arXiv the author's PDFs or an open-access copy (`overlap.library.library_text`); at most 90k characters. A work without text is excluded with that reason. |
| Extraction | `extractor` (`extract_effect`, schema `effect`), one call per work: found, setting, indirect (and why), metric, higher_is_better, unit (percent, fraction, other), method and comparator (label, value as written, quote, location), spread_kind (sd, se, ci95 half-width, none) with each arm's spread and quote, and runs with its quote. `check_effect`: a number is kept only when its quote is in the text (whitespace and typographic quotes folded) and the number stands in the quote as a number of its own; a study whose method or comparator number fails is excluded; a spread or run count that fails is dropped and noted. A study whose method and comparator numbers are the same as an earlier study's (a benchmark copied into a follow-up paper) is left out as a duplicate publication. A reply that cannot be read is asked once more. |
| Risk of bias | `assessor` (`assess_bias`, schema `risk_of_bias`), one call per extracted study, on four items: seeds, test-set tuning, contamination, comparator tuned (the seeds and test-tuning texts reuse method_lint's `no-seed` and `test-in-tuning` explanations). A low or high judgement whose quote is not in the text becomes unclear. Code sets seeds to low when the extraction verified two or more runs, and decides code release from a GitHub, GitLab, Bitbucket or Hugging Face link or a "code is available" sentence in the text. When the assessor fails twice, every item stays unclear and the study is kept. Overall: high when test tuning, contamination or comparator tuning is high; some concerns when an item is unclear or seeds or code release is high; else low. |
| Pooling (code) | Effect = method minus comparator, negated when lower is better, times 100 for fractions (percentage points). Variance from each arm's SD over n runs (n = 1 when not said), SE, or 95% CI half-width; a spread for one arm is used for both; never below the rounding of the reported numbers. Studies without a spread get the median SD of those that report one (Cochrane Handbook 6.5.2.7). Studies in a unit other than the majority are excluded. DerSimonian–Laird random effects: tau², I², Q, 95% CI and z test, prediction interval with t(k−2) from 3 studies; with no spread anywhere, the unweighted mean with a t(k−1) interval. Egger's regression test from 10 studies. Leave-one-out sensitivity from 3 studies: a study whose studentized deleted residual exceeds 1.96 (Viechtbauer & Cheung 2010), or whose removal moves the pooled effect outside the full CI, is flagged as an outlier in the notes for the author to check. Standard library only (t distribution from `methods.significance`). |
| GRADE (code) | Starts High (controlled experiments). Risk of bias −1 when high-risk studies carry more than half the weight; inconsistency −1 when I² > 50% (unweighted: effects on both sides of 0); indirectness −1 when indirect studies carry more than half the weight; imprecision −1 when the CI crosses 0 and −1 for fewer than 3 studies or no reported spread; publication bias −1 when Egger p < 0.10. High, Moderate, Low or Very low. |
| Output | JSON with `status`, `report`, `run`, `forest`, `studies_file`, `screening`, `candidates`, `included`, `studies`, `kappa`, `effect`, `ci`, `i2`, `certainty`. `PASS`: pooled over 3 or more studies at Moderate or High certainty, with no failed call or unavailable source. `FAIL`: no study extractable. `PASS_WITH_NOTES` otherwise. Files in `<out_dir>/<timestamp>/`: `report.md` (Chinese: summary-of-findings table, downgrade reasons, included studies with every quote, risk-of-bias table, screening agreement and disagreements, exclusions), `forest.html` (self-contained forest and funnel plots in inline SVG, light and dark), `studies.csv`, `screening.csv`, `analysis.json`, `run.json`, `run.md`; the full-text cache in `<out_dir>/cache`. |
| Effects | Reads the project's .bib files and field surveys; writes only the output folder and its cache. |
| Model calls | Each screener one call per 15 works plus retries; one extractor call per included work with text; one assessor call per extracted study. Twelve works make about 2 + 2 × 10 calls. |
| Failure | A failed call or an unusable reply is a note (the work is left unscreened, or excluded), and the status is at most PASS_WITH_NOTES; a source that does not answer is named. Rerunning is safe. |
| Tests | `tests/metaanalysis/test_stats.py`: t quantiles against tables, DerSimonian–Laird against its formulas, I² and the prediction interval, no tau² for homogeneous studies, variances from SD, SE and CI, imputation and the rounding floor, unweighted pooling, Egger on symmetric and asymmetric funnels, leave-one-out finding an outlier, each GRADE downgrade. `tests/metaanalysis/test_workflow.py`: scripted screeners, extractor and assessor with every network call replaced; blind screening, a wrong quote asked again, kappa, disagreements, quotes checked, an invented number excluded, a fraction error rate turned into points, imputed variances, risk-of-bias cross-checks, a failed assessor keeping the study, duplicate numbers counted once, pooled result, report, forest.html and CSVs; nothing extractable fails; three screeners on named models; inputs and .bib candidates. |
| Usage | `from auto_research.tasks.metaanalysis import meta_analysis` |

## Not covered

- Registering the task in the program's task list and app.
- An author file to resolve screening disagreements; the report lists them and every included work is read.
- Several effects per study (one per work, the closest to the question), multi-arm studies, or ratio measures (log odds, risk ratios).
- Searching for works: give `works`, or run field_survey first.
