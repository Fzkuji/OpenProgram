# deepread tool

`deep_read` reads one work at five zoom levels, explains how its equations are derived, and marks its references by the author's own reading and citing history (`tasks/deepread/`). It takes the project's Git repository as `paper_dir` (anything else raises `ValueError`), writes into `<out_dir>/<timestamp>/` with a trail (`run.json`, `run.md`), and returns JSON with `status`, `report` and `run`. The report is in Simplified Chinese. Code fetches, parses and checks; the roles only summarize and explain, and every quote and every equation number they give is checked in code.

Learned from PaperFold (zoom levels from a one-line overview down to the verbatim text), Nujan (math derivations broken into small steps) and CiteSee (inline citations marked by the reader's own reading and citing history).

## deep_read

| Item | Contract |
| --- | --- |
| Signature | `deep_read(paper_dir, work, out_dir="")` |
| Purpose | The author reads a work at the depth they need, with every summary statement backed by a verbatim quote, every derivation step naming the equations it uses, and the references they have not seen yet ranked by how much the work leans on them. |
| Input | `paper_dir`: the project's Git repository. `work`: an arXiv id (`2010.11929`, `arXiv:2010.11929`, an abs/pdf URL, old-style `hep-th/9901001`), a DOI (`10.x/...`, `doi:`, a doi.org URL; `10.48550/arXiv.*` is read as arXiv), or the path of an existing PDF. `out_dir`: default `<paper_dir>/drafts/deep_read`. An empty or unrecognized `work`, or a `.pdf` path that does not exist, raises `ValueError`. |
| Fetch | arXiv: `https://arxiv.org/e-print/<id>`, read in memory (tar.gz, tar, a gzipped single file, or a PDF); only `.tex`, `.bbl`, `.bib` members under 4 MB, never extracted. The main file holds `\documentclass` and `\begin{document}` (main/ms/paper first, else the largest); `\input`, `\include` and `\subfile` are inlined, comments stripped. No usable source: `https://arxiv.org/pdf/<id>` and `pdftotext`. DOI: Semantic Scholar `paper/DOI:<doi>` (`externalIds.ArXiv`, `openAccessPdf`), then OpenAlex `works/doi:<doi>` (an arXiv location, `best_oa_location.pdf_url`). JSON requests go through `citations.sources.fetch`; byte downloads through `source.fetch_bytes` (same retries, same `UNAVAILABLE` record). A downloaded PDF is kept as `source.pdf`. |
| Structure (LaTeX) | The body between `\begin{document}` and `\end{document}`, bibliography commands removed. The source's own no- and one-argument macros (`\newcommand`, `\renewcommand`, `\providecommand`, `\def`) are expanded in prose. Sections from `\section` to `\subsubsection` (starred unnumbered; after `\appendix` lettered) and the abstract; paragraphs split at blank lines and at `\paragraph{}`; floats give their captions as paragraphs (`Figure n: ...`). `\cite*` become `[cite: k1, k2]`; `\ref`/`\eqref` of equation, section, figure and table labels become their numbers. Display environments (`equation`, `align`, `gather`, `multline`, `eqnarray`, `flalign`, `alignat`, `displaymath`, `\[ \]`, `$$ $$`) are numbered as LaTeX does: each align-like row unless `\nonumber`/`\notag`, `\tag` kept, starred none. References: every cited key in order of first citation, with how often it is cited; title, authors, year, venue, arXiv id and DOI from the archive's `.bib`, else its `.bbl` (`\newblock` parts). |
| Structure (PDF) | Blocks between blank lines, page numbers dropped, hyphenated line ends joined. Short numbered lines and common section names are headings; the References heading starts the reference list (`[n]` entries, else one per block; title guessed from the second sentence, arXiv id and DOI by pattern). Numeric citations `[3]`, `[3, 5]`, `[3-5]` are counted. No equations. |
| History | A reference is `cited` when it matches an entry of the project's `.bib` (`library.resolve.entries`), `read` when it matches a work named by `workflow/annotations.csv` (`key`, written by import_annotations), `literature.md`, `literature_table.csv` (`key`), `claim_support.csv` (`work`), a field survey's kept papers (`workflow/surveys/*/*/survey.json`, decision core, adjacent or survey, written by research_survey) or a handled row of `watch.csv`; otherwise `new`. Matching is by arXiv id, DOI, or title similarity ≥ 0.93 (`citations.refs.title_sim`). Order: new first, most cited inside the work first; then read; then cited. |
| Model calls | `reader` (`read_sections`, schema `section_reading`): one call per part of about 6,000 characters of paragraphs (a long section is split across parts): one to four level-3 statements per section and, under each section, exactly one level-4 point per paragraph, each with its paragraph id and a quote. `condenser` (`condense`, schema `paper_overview`): one call; level 1 (one sentence) and level 2 (three to eight statements) from the abstract and the checked section summaries. `deriver` (`derive`, schema `derivations`): one call per 30 displays (none for a PDF); for each display that follows from earlier equations, the target equation and up to 8 steps, each listing the equations it uses. Summaries are written in Simplified Chinese; quotes stay in the paper's language. |
| Check | A quote must have three or more words and occur in the named paragraph, citation markers removed, whitespace and typographic quotes normalized, case ignored; found in another paragraph it is re-attributed there; found nowhere, the statement or point is dropped and listed in `dropped`. A reply naming a section, paragraph or display it was not given raises; a reader reply that is not valid JSON after the retries leaves its sections without summaries and is noted. A derivation is dropped when its target is not an equation of the display, a step cites no equation, cites an equation number or display id that does not exist, or cites one that does not come before the target. |
| Output | JSON with `status`, `report` (report.md), `html`, `md`, `run`, `source` (`latex`, `pdf` or empty), `paragraphs`, `points`, `derivations`, `references` (`new`, `read`, `cited`), `dropped`, `unavailable_sources`. `FAIL`: no paragraph could be read (nothing downloaded, or an empty text). `PASS_WITH_NOTES`: a source failed, the work was read from a PDF, a paragraph has no checked point, the level-1 sentence was dropped, or anything was dropped. `PASS` otherwise. Files: `read.html` (plain HTML and CSS with a few lines of inline script that open the folded levels on a link; L1 shown, L2 open, per section L3, L4 points linking to their paragraphs, L5 verbatim paragraphs with citation chips coloured cited/read/new and displays with their derivations; a references table), `read.md` (the same in Markdown), `read.json` (everything, including what was dropped and why), `report.md`, `run.json`, `run.md`, `source.pdf` when a PDF was downloaded. |
| Effects | Network: arXiv e-print and PDF, Semantic Scholar and OpenAlex for a DOI. `pdftotext` runs with a 180 s timeout. Reads the project's `.bib` and `workflow/`; never writes them. |
| Tests | `tests/deepread/test_deep_read.py`: an in-memory arXiv tarball with `\input`, macros, an align with `\nonumber`, a figure caption, `\paragraph`, an appendix; section, equation, figure and label numbering; tags, starred and split environments; macro expansion; parsing of every `work` form; gzip, tar and PDF e-prints; a PDF's sections and numeric citation counts; the full run with scripted roles (a dropped and a re-attributed quote, a derivation with a non-existent and with a later equation, history from the .bib and a survey, the HTML links and chips, the stage order); a DOI through Semantic Scholar; the PDF fallback and a work that cannot be downloaded; replies naming paragraphs or displays they were not given; history from annotations.csv and watch.csv. |
| Not covered | Macros with two or more arguments, `\newenvironment`, and author-year citation counting in PDFs; equation numbering reset per section (`\numberwithin`); figures and tables themselves (only their captions); scanned PDFs without a text layer. |
| Usage | `from auto_research.tasks.deepread import deep_read` |
